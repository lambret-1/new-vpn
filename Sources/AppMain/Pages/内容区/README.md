# 内容区组件说明

## 组件列表

- **节点内容区**：节点分组列表展示，支持分组展开/收起、分组批量测速、节点右滑测速、节点长按上下文菜单（节点测试/复制链接/编辑/删除/移动分组）、删除节点二次确认、移动分组选择、编辑节点页面、Toast提示
- **规则与日志内容区**：分流规则和日志展示

## 功能说明

### 节点内容区
- 分组按订阅名称聚合，常驻显示
- 分组标题行支持点击展开/收起，长按复制/分享分组 JSON
- 节点行支持右滑露出测速按钮
- 节点行支持长按唤起上下文菜单（所有正常节点均启用）
- 上下文菜单：节点测试、复制节点链接、编辑节点、移动至其他分组、删除节点
- 复制节点链接生成完整标准协议链接（VLESS/VMess/Trojan/Shadowsocks），包含协议、地址、端口、UUID、加密、路径、Host、SNI等全部参数，复制成功后弹出Toast提示"节点链接已复制"
- 编辑节点页面：支持修改名称、地址、端口、UUID/密码、传输类型、TLS、SNI、WebSocket路径/Host、分组、备注，保存后自动刷新节点列表
- 删除节点弹出二次确认弹窗，防止误删
- 移动分组页面：展示全部分组列表，当前分组标记"当前"标签，选择当前分组弹窗提示"不能移动至当前分组"，支持创建新分组，增加取消按钮
- 移动成功后自动刷新节点列表UI，同步更新本地持久化数据
- Toast轻量提示：底部弹出，2秒自动消失
