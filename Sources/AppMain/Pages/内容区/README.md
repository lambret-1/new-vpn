# 内容区组件说明

## 组件列表

- **节点内容区**：节点分组列表展示，支持分组展开/收起、分组批量测速、节点右滑测速、节点长按上下文菜单（节点测试/复制链接/编辑/删除/移动分组）、删除节点二次确认、移动分组选择
- **规则与日志内容区**：分流规则和日志展示

## 功能说明

### 节点内容区
- 分组按订阅名称聚合，常驻显示
- 分组标题行支持点击展开/收起，长按复制/分享分组 JSON
- 节点行支持右滑露出测速按钮
- 节点行支持长按唤起上下文菜单（仅有效节点显示）
- 上下文菜单：节点测试、复制节点链接、编辑节点、移动至其他分组、删除节点
- 删除节点弹出二次确认弹窗，防止误删
- 移动分组支持选择已有分组或创建新分组
- 操作完成后自动刷新节点列表 UI，同步更新本地持久化数据
