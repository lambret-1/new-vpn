# 内容区组件说明

## 组件列表

- **节点内容区**：节点分组列表展示，支持分组展开/收起、分组批量测速、节点右滑测速、节点长按上下文菜单（节点测试/复制链接/编辑/删除/移动分组）、删除节点二次确认、移动分组选择、编辑节点页面、Toast提示
- **策略组内容区**：出站策略组（selector/urltest）管理，支持展开/收起节点列表、实时延迟显示、手动切换节点、单节点测速、自动测速组
- **规则与日志内容区**：分流规则和日志展示
- **网络活动内容区**：TCP/UDP 连接监控，含 CPU/内存/扩展内存四宫格统计、扩展内存分桶可视化（日志/DNS/连接/计时表条数占比堆叠条、可用内存、压力事件、清理释放量）、连接记录列表与详情页

## 功能说明

### 策略组内容区
- 从 sing-box Clash API（http://127.0.0.1:9090/proxies）实时获取策略组数据，5秒轮询更新
- 策略组按类型排序：selector（手动选择）在前，urltest（自动测速）在后
- 卡片头部显示：组名、类型标签、当前选中节点、当前节点延迟、节点总数、展开/收起箭头
- 展开后显示组内全部节点列表，每行显示：选中指示器、节点名称、延迟、测速按钮
- 节点默认按延迟由低到高自动排序
- 延迟颜色分级：<100ms绿色、<300ms黄色、超时红色、未测灰色
- 点击节点行切换选中节点（selector类型），切换中显示加载指示器
- 点击测速按钮对单个节点进行延迟测试，测速中显示加载指示器
- 批量测速：策略组卡片头部测速按钮，串行测速全部节点，显示进度（已测/总数）
- 长按节点菜单：复制节点名称、测试延迟、切换到此节点
- 复制成功提示：底部弹出轻量提示，1.5秒自动消失
- 顶部导航策略组卡片实时显示第一个策略组的当前节点和延迟
- VPN未连接提示：顶部橙色警告条，提示策略组数据可能未更新
- 空状态：无策略组时显示引导提示

### 节点内容区
- 分组按订阅名称聚合，常驻显示
- 分组标题行支持点击展开/收起，长按复制/分享分组 JSON
- 节点行支持右滑露出测速按钮
- 节点行支持长按唤起上下文菜单（所有正常节点均启用）
- 上下文菜单：节点测试、复制节点链接、编辑节点、移动至其他分组、删除节点
- 复制节点链接生成完整标准协议链接（VLESS/VMess/Trojan/Shadowsocks），包含协议、地址、端口、UUID、加密、路径、Host、SNI等全部参数，复制成功后弹出Toast提示"节点链接已复制"
- 编辑节点页面：标签+输入框成对规整排列，按基础信息/传输/TLS/WebSocket/安全/分组备注分模块，每个字段有标签和占位提示(地址提示域名/IP、UUID提示VLESS UUID、路径提示WebSocket路径)；字段校验(端口1~65535、UUID格式、地址非空)校验失败红色提示阻止保存；传输类型切换动态显示/隐藏对应配置，关闭TLS自动隐藏SNI；有修改才启用保存按钮无修改置灰；保存成功Toast提示失败展示具体错误；输入框支持长按复制粘贴删除；长文本支持滚动
- 删除节点弹出二次确认弹窗，防止误删
- 移动分组页面：展示全部分组列表，当前分组标记"当前"标签，选择当前分组弹窗提示"不能移动至当前分组"，支持创建新分组，增加取消按钮
- 移动成功后自动刷新节点列表UI，同步更新本地持久化数据
- Toast轻量提示：底部弹出，2秒自动消失
