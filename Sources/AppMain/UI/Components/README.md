# UI 组件目录

本目录存放 NewVPN 应用的所有可复用 UI 组件。

## 组件清单

### 基础组件
- **AppButton**：统一按钮样式，支持主按钮、次要按钮、危险按钮
- **AppCard**：卡片容器，统一圆角、阴影、内边距
- **AppFormRow**：表单行组件，支持左标题右值、开关、输入框
- **AppSearchBar**：搜索栏组件
- **StateBadge**：状态徽章，支持连接/断开/错误等状态
- **EmptyStateView**：空状态视图，支持图标+标题+副标题+操作按钮

### 业务组件
- **底部工具栏**：底部固定 5 功能入口，点击弹出底部弹窗；设置图标长按弹出运行模式选择面板
- **底部弹窗容器**：底部 95% 高度弹窗容器，支持下滑关闭
- **运行模式选择面板**：顶部下拉面板，长按设置图标触发，支持规则分流/全局代理/全局直连切换；MitM、重写、HTTP 抓取为预留功能
- **顶部功能卡片栏**：横向滚动功能卡片，切换主内容区
- **全局状态栏**：顶部全局状态展示
- **测速组件**：节点测速进度与结果展示
- **分流规则组件**：分流规则列表与编辑
- **隧道组件**：隧道状态展示与控制
- **DNS组件**：DNS 记录展示
- **SingBox组件**：sing-box 内核状态与配置
- **订阅管理视图**：订阅链接管理
- **订阅解释器视图**：订阅解析结果展示
- **新增订阅弹窗**：添加订阅链接弹窗
- **证书与描述文件组件**：证书与描述文件管理
- **配置描述文件组件**：VPN 配置描述文件管理
- **调试日志组件**：调试日志查看
- **MITM设置页面**：MITM（HTTPS 中间人解密）功能设置，证书文件管理深度重构(crt+key成对原子写入)，TLS指纹模拟(uTLS可自定义Chrome/Firefox/Safari/Edge/iOS/Android指纹，降低EdgeOne等WAF的Bot防护识别拦截概率)，域名MITM排除列表(对强WAF防护域名单独关闭MITM解密直接透传原始TLS会话，支持添加/删除/启用开关/备注)，连接事件日志(区分TLS握手成功并解密、站点WAF返回567拦截、TLS握手失败、域名排除透传)，证书有效性实时检测，页面加载等待检测完成再渲染UI，全自动探测证书状态，探测失败兜底手动确认，证书日志查看，临近过期提醒
- **重写规则设置页面**：URL 重写规则管理，支持URL重写/请求头/响应头/请求阻断，分组管理和预设导入
- **抓包列表页面**：HTTP 抓包记录列表，功能开关(热更新无需重启VPN)、热更新状态显示、统计栏(总请求/错误/HTTPS)、搜索过滤、高级筛选面板(方法/状态/状态码范围/响应大小/过滤规则保存)、请求响应大小显示、清空记录、HAR导出、分页加载(每页50条)、自动刷新、点击跳转详情页
- **抓包详情页面**：HTTP 抓包记录详情，请求/响应 Tab 切换，请求行/响应行展示，Headers 列表(可复制)，Body 多格式查看(自动/原始/JSON格式化)，cURL 命令导出，URL 复制，直接重放，编辑后重放，重放结果展示，请求时间线，单条记录导出(JSON/HAR)
- **下载进度视图**：应用更新下载进度
- **AppUpdateAlert**：应用更新提示弹窗

## 设计规范

- 所有组件引用 `UIConst.swift` 中的设计令牌（颜色/字体/间距/圆角）
- 间距基于 8pt 网格
- 适配浅色/深色模式
- 适配安全区与动态字体
- 组件需覆盖加载、空态、错误、按下等全部状态

## 运行模式选择面板说明

- **触发方式**：长按底部工具栏最右侧设置图标（≥0.5秒）
- **面板位置**：从顶部往下滑出，带半透明灰色遮罩
- **关闭方式**：点击遮罩非功能区、选择模式后自动关闭
- **三个模式**：
  - 规则分流：按分流规则匹配，国内直连、国外代理
  - 全局代理：所有流量全部走代理服务器
  - 全局直连：所有流量直接连接，不经过代理
- **预留功能**：MitM、重写、HTTP 抓取（后续开发，当前显示为灰色待开发状态）
- **切换行为**：选择模式后立即更新配置，若隧道已连接则自动重新加载
