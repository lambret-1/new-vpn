## 一期第二次交付内容（Dashboard 重构）

### 主控首页 Dashboard
- 顶部状态区：左侧隧道状态文字 + 右侧电源开关
- 横向功能卡片栏：5 张可滑动卡片（节点/网络活动/重写规则/分流规则/日志）
- 主内容区：根据选中卡片切换对应内容
- 底部固定工具栏：5 个功能入口（编辑配置/DNS记录/JS脚本/TCP-UDP流量/设置）

### 精确尺寸规范（基于截图测量）
- 顶部卡片：宽 102pt × 高 74pt，间距 16pt，左边距 12pt，圆角 16pt
- 卡片颜色：节点 #3DC4D2、网络活动 #E75C33、重写规则 #FC54A1、分流规则 #5AC8FA、日志 #6B6B70
- 分组/节点行：左右边距 15pt，圆角 12pt
- 底部工具栏：高 56pt，毛玻璃背景

### 交互功能
- 顶部卡片点击切换内容区，选中卡片高亮
- 分组行点击展开/折叠节点列表（平滑动画）
- 分组左侧测速图标点击触发模拟批量测速
- 节点行展示协议标签、地址、测速下载速率和延迟
- 底部工具栏点击弹出 90% 高度底部 sheet
- 弹窗左上角向下箭头点击关闭，支持下滑手势关闭

### 底部弹窗内容
- 编辑配置文件：配置列表 + 导入/导出/编辑操作
- DNS 记录：DNS 查询记录列表
- JS 脚本记录：已执行脚本日志
- TCP/UDP 流量：连接数统计 + 实时速率
- 设置：通用/网络/关于设置项，含检查更新入口

## 一期第三次交付内容（检查更新）

### 更新检测功能
- App 启动时静默后台检测更新（有新版本才弹窗）
- 设置页面手动触发检查更新
- 检测中弹窗：半高（45%屏幕），蓝色圆形加载动画 + 步骤文本
- 发现新版本弹窗：完整高度（82%屏幕），版本信息卡片 + 下载按钮
- 已是最新版本弹窗：半高，成功图标 + 关闭按钮
- 检测失败弹窗：半高，错误信息 + 重试/关闭

### 下载更新功能
- 点击下载更新后弹窗切换为下载进度视图
- 圆环进度 + 百分比 + 已下载/总大小 + 下载速度 + 线性进度条
- 支持取消下载
- 下载完成后自动关闭弹窗，弹出 iOS 系统分享面板
- 下载文件仅存临时目录，分享面板关闭后60秒自动清理
- 用户可在分享面板选择存储到文件、隔空投送、侧载安装等

### 版本管理
- 语义化版本比较（major.minor.patch）
- 忽略此版本：保存到 UserDefaults，后续静默检测跳过
- 稍后提醒：24小时冷却期内不再自动弹窗

## 架构原则

- UI 与数据层通过 AppState 解耦
- 所有页面引用设计令牌，禁止硬编码样式
- 后续接入真实数据只需替换 AppState 数据源，View 层无需修改
- Dashboard 采用单栏布局，适配 iPhone 竖屏
