# 01 - 项目总览

## 1.1 项目定位

iOS 平台原生网络代理客户端，基于 sing-box 内核，以 TUN 虚拟网卡方式接管系统流量。
面向个人使用场景，不上架 App Store，CI 流水线产出未签名 IPA，由开发者自行签名安装。

## 1.2 技术约束

| 项 | 约束 | 说明 |
| --- | --- | --- |
| 语言 | Swift 5.9+ | 全中文注释、变量名、文件名 |
| UI 框架 | SwiftUI | 最低 iOS 16 |
| 最低系统 | iOS 16.0 | 不兼容 iOS 15 及以下 |
| 内核 | sing-box | 编译进 PacketTunnel 扩展进程 |
| 工程管理 | XcodeGen | `project.yml` 生成 `.xcodeproj` |
| CI/CD | GitHub Actions | macOS 14 runner，Xcode 15.4 |
| 跨进程 | App Group + IPC | 主 App ↔ PacketTunnel 扩展 |
| JS 引擎 | JavaScriptCore | 系统框架，无需第三方依赖 |
| 禁止项 | Flutter / React Native / WebView | 纯原生实现 |
| 弹窗规范 | `fullScreenCover` | 左上角返回按钮 + 边缘左滑关闭 |
| 命名规范 | 全中文 | 用户可见字符串、日志、错误提示 |

## 1.3 功能范围

### 核心功能（一期必做）

- **TUN 隧道**：启动 / 停止、自动重连、实时流量统计
- **节点管理**：手动新增、分组标签、vmess / vless 链接解析
- **订阅管理**：多订阅源、Base64 解码、流量 / 过期解析、定时更新
- **分流路由**：自定义规则、内置规则集、热重载
- **测速**：延迟、抖动、丢包、上下行带宽
- **MITM**：根证书管理、HTTP 请求 / 响应重写
- **HTTP 抓包**：会话捕获、JSON 格式化、HAR 导出
- **网络活动**：四层 TCP / UDP 连接监控、IP 地理解析
- **JS 脚本**：JavaScriptCore 沙箱、事件钩子、内置 API
- **调试日志**：分级日志、环形缓冲、滚动文件、脱敏
- **设置**：全局配置、备份导入导出、恢复出厂
- **UI**：三栏面板、深浅主题、全中文

### 非目标（一期不做）

- 不上架 App Store
- 不提供代码签名服务
- 不支持 trojan / ss / ssr 等协议（订阅中出现直接过滤）
- 不支持 HTTP/3（QUIC）MITM 解密
- 不做跨平台 Android / macOS 版本

## 1.4 版本规则

三段式语义版本 `vX.Y.Z`：

| 位 | 含义 | 进位条件 |
| --- | --- | --- |
| X | 大版本架构变更 | 不兼容重构 |
| Y | 新增功能模块 | 新增完整模块 |
| Z | 补丁修复 | BUG 修复、小优化 |

CI 自动进位规则：手动触发选择 `patch` / `minor` / `major`，默认 `patch`。
