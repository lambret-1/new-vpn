# 01 - 项目总览

## 1.1 项目目标

iOS 平台原生网络代理客户端，基于 sing-box 内核，支持 TUN 隧道，实现节点管理、订阅解析、分流、MITM、抓包、网络监控、JS 脚本扩展、日志调试。SwiftUI 三栏面板，深浅色主题，全中文界面。

## 1.2 技术约束

| 项 | 约束 |
| --- | --- |
| 平台 | iOS 16+ |
| UI | SwiftUI，`NavigationSplitView` 三栏布局 |
| 内核 | sing-box，运行于 PacketTunnelProvider 扩展进程 |
| 工程 | XcodeGen 生成 `project.yml` |
| CI/CD | GitHub Actions，输出未签名 IPA |
| 跨进程 | App Group + IPC，主 App 与 Tunnel 扩展通信 |
| JS 引擎 | JavaScriptCore |
| 禁止 | Flutter、跨端框架、WebView |
| 弹窗 | 全部使用 `fullScreenCover`，左上角返回 + 左滑关闭 |
| 本地化 | 全中文（注释、日志、提示、变量名、文件名） |

## 1.3 功能范围

### 已规划功能

- TUN 隧道启停、自动重连、流量统计
- 节点管理（手动新增 / 订阅导入，vmess / vless）
- 订阅源管理、订阅解释器（Base64 解码、流量 / 过期解析、过滤）
- 测速模块：延迟、抖动、丢包、带宽测试
- 分流路由规则，支持热重载
- MITM 中间人、HTTP 请求 / 响应重写
- HTTP 抓包会话查看、HAR 导出
- 四层网络活动监控、CSV 导出
- JS 脚本系统 + JS 解释器，多事件钩子
- 分级调试日志、日志导出、脱敏
- 系统设置、备份导入导出、关于页面
- 统一简洁 SwiftUI 组件库

### 非目标

- 不上架 App Store
- 不提供代码签名
- 不支持 trojan / ss / ss-r 等其他协议（订阅中出现直接过滤）
- 不支持 HTTP/3（QUIC）MITM 解密

## 1.4 版本规则

三段式语义版本 `vX.Y.Z`：

- X：大版本架构变更
- Y：新增功能模块
- Z：补丁修复，CI 自动进位，范围 0-9，超出则 Y+1
