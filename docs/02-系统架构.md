# 02 - 系统架构

## 2.1 分层架构

```
┌─────────────────────────────────────────────┐
│  UI 层                                       │
│  面板 UI 模块 + UI 基础组件库                 │
│  （SwiftUI，NavigationSplitView 三栏）       │
└──────────────────────┬──────────────────────┘
                       │ 调用业务 API / 监听 @Published
┌──────────────────────▼──────────────────────┐
│  业务逻辑层                                   │
│  VPN 模块                                    │
│  节点模块                                    │
│  订阅管理器 + 订阅解释器                     │
│  测速模块                                    │
│  分流路由模块                                 │
│  MITM & HTTP 重写模块                        │
│  HTTP 抓包模块                               │
│  网络活动模块                                 │
│  JS 脚本模块 + JS 解释器                     │
│  调试日志模块                                 │
│  配置管理模块                                 │
└──────────────────────┬──────────────────────┘
                       │ 组装配置 / IPC 事件
┌──────────────────────▼──────────────────────┐
│  内核层                                      │
│  sing-box（PacketTunnelProvider 进程内）      │
└─────────────────────────────────────────────┘
```

## 2.2 模块依赖关系

| 模块 | 依赖 | 说明 |
| --- | --- | --- |
| 配置管理 | 无 | 底层基础，所有模块读写配置 |
| 调试日志 | 配置管理 | 被全部模块依赖，统一日志输出 |
| VPN 模块 | 节点、分流、MITM、配置、日志 | 隧道与 sing-box 配置组装 |
| 订阅解释器 | 网络组件、日志 | 输出节点中间模型给节点模块 |
| 节点模块 | 配置、日志 | 为 VPN 模块提供出站配置片段 |
| 面板 UI | 全部业务模块 | 仅做视图渲染，不承载业务逻辑 |
| JS 脚本模块 | JS 解释器、日志 | 可调用节点 / VPN 接口 |
| 测速 / 抓包 / 网络活动 / MITM | 日志、配置 | 内核事件回调驱动 |

## 2.3 数据流

1. 用户在面板触发操作 → 调用业务模块异步 API
2. 业务模块校验、处理，更新 `@Published` 状态
3. 状态变更自动驱动 UI 刷新
4. VPN 模块组装 sing-box 配置写入 App Group 共享目录
5. Tunnel 进程读取配置启动 sing-box
6. 内核事件、日志、流量统计通过 IPC 回传给主 App
7. 主 App 转发内核信息至日志 / 流量 / 抓包 / 网络活动模块

## 2.4 进程模型

### 主 App 进程

- SwiftUI 面板
- 业务逻辑层全部模块
- 生成 sing-box 配置
- 唤起 / 停止 PacketTunnel
- 接收 IPC 事件并更新 UI

### PacketTunnel 扩展进程

- 读取 App Group 共享目录内 sing-box 配置
- 启动内嵌 sing-box
- 创建 TUN 设备
- 接管网络流量，执行路由、DNS、出站转发
- 采集流量统计，通过 IPC 回传
- 输出内核日志，IPC 转发到主 App

### App Group 共享目录

```
group.<bundle-id>.shared/
├── config/
│   └── singbox.json          # 主 App 写入，Tunnel 读取
└── logs/
    └── tunnel.log            # Tunnel 写入，主 App 读取
```

## 2.5 单向数据流原则

- UI 不直接操作内核
- UI 只调用业务模块 API
- 业务模块通过 `@Published` 状态通知 UI
- 禁止反向依赖：UI → 业务 → 内核，不允许内核直接调用 UI
- 模块间通过协议 / 事件总线解耦
