┌──────────────────────▼──────────────────────────┐

│  ┌──────────┐ ┌──────────┐ ┌──────────┐         │

│  └──────────┘ └──────────┘ └──────────┘         │

## 2.2 模块依赖关系

| 模块 | 直接依赖 | 被依赖 |
| --- | --- | --- |
| 配置管理 | 无 | 全部模块 |
| 调试日志 | 配置管理 | 全部模块 |
| VPN 模块 | 节点、分流、MITM、配置、日志 | 面板 UI |
| 订阅解释器 | 网络组件、日志 | 订阅管理器 |
| 订阅管理器 | 订阅解释器、节点、配置、日志 | 面板 UI |
| 节点模块 | 配置、日志 | VPN、订阅、测速、面板 UI |
| 测速模块 | 节点、配置、日志 | 面板 UI |
| 分流模块 | 配置、日志 | VPN、面板 UI |
| MITM 模块 | 配置、日志 | VPN、抓包、面板 UI |
| HTTP 抓包 | MITM、配置、日志 | 面板 UI |
| 网络活动 | 配置、日志 | 面板 UI |
| JS 脚本 | JS 解释器、日志、节点、VPN | 面板 UI |
| 面板 UI | 全部业务模块 | 无（顶层） |

> 依赖方向：UI → 业务 → 内核，严格单向，禁止循环依赖。

## 2.3 进程模型

### 主 App 进程

- SwiftUI 面板（`NavigationSplitView`）
- 全部业务逻辑模块
- 生成 sing-box 配置
- 唤起 / 停止 PacketTunnel
- 接收 IPC 事件，更新 UI 状态

### PacketTunnel 扩展进程

- 读取 App Group 共享目录内 sing-box 配置
- 启动内嵌 sing-box
- 创建 TUN 虚拟网卡
- 接管系统流量，执行路由、DNS、出站转发
- 采集流量统计，通过 IPC 回传主 App
- 输出内核日志，IPC 转发到主 App

### App Group 共享目录

```
group.com.newvpn.shared/
├── config/
│   └── singbox.json          # 主 App 写入，Tunnel 读取
├── logs/
│   └── tunnel.log            # Tunnel 写入，主 App 读取
└── runtime/
    └── ipc_socket             # IPC 通信套接字
```

## 2.4 数据流

### 启动隧道流程

```
用户点击启动
    ↓
面板 UI 调用 VPNManager.startTunnel(nodeId)
    ↓
节点模块：获取出站配置片段
    ↓
分流模块：获取规则配置片段
    ↓
MITM 模块：获取重写配置片段
    ↓
VPN 模块：组装完整 sing-box JSON
    ↓
写入 App Group 共享目录
    ↓
唤起 PacketTunnel
    ↓
Tunnel 读取配置，启动 sing-box
    ↓
TUN 网卡创建，流量接管
    ↓
IPC 回传 running 状态
    ↓
面板 UI 更新状态指示灯
```

### 运行时事件流

```
sing-box 内核事件
    ↓
Tunnel 扩展采集
    ↓
IPC 通道 → 主 App
    ↓
事件分发：
    ├─ 流量统计 → AppState（面板实时刷新）
    ├─ 内核日志 → Logger 模块
    ├─ 连接事件 → 网络活动模块
    └─ MITM 解密流 → 抓包模块 / 重写模块
```

## 2.5 单向数据流原则

- UI 不直接操作内核
- UI 只调用业务模块公开 API
- 业务模块通过 `@Published` 状态通知 UI
- 禁止反向依赖（内核 → UI）
- 模块间通过协议 / 事件总线解耦
- 数据修改必须走业务模块，UI 不可直接改数据模型

## 2.6 线程模型

| 层级 | 线程 | 说明 |
| --- | --- | --- |
| UI 渲染 | 主线程 | SwiftUI 必须在主线程更新 |
| 业务逻辑 | 后台队列 | 网络请求、文件读写、配置解析 |
| 内核事件 | Tunnel 进程独立队列 | sing-box 事件循环 |
| IPC 通信 | 后台队列 | 不阻塞 UI |

> UI 更新节流：流量、日志等高频数据，每 200-300ms 批量刷新一次。
