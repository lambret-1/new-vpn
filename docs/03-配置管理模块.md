# 03 - 配置管理模块

## 3.1 职责

- 统一读写全部 JSON 配置文件
- 配置版本迁移与升级兼容
- 配置打包导出 / 导入恢复
- 导出密钥脱敏
- 配置文件读写加锁，防止并发损坏
- JSON 语法校验，非法配置拦截
- 配置损坏自动恢复

## 3.2 数据文件清单

| 文件 | 说明 | 大小预估 |
| --- | --- | --- |
| `config.json` | 全局应用设置 | < 10KB |
| `nodes.json` | 节点列表、分组、标签、测速缓存 | < 500KB |
| `subscriptions.json` | 订阅源配置、meta 信息、过滤规则 | < 50KB |
| `rules.json` | 分流路由规则 | < 100KB |
| `rewrite.json` | MITM HTTP 重写规则 | < 100KB |
| `scripts.json` | JS 脚本配置 | < 500KB |
| `logs/` | 日志文件目录 | 滚动限制 |

## 3.3 数据模型

```swift
/// 配置文件协议
protocol ConfigFile: Codable {
    static var fileName: String { get }
    var version: String { get set }
}

/// 全局主配置
struct AppConfig: ConfigFile {
    var version: String
    var appSettings: AppSettings
    var backup: BackupSettings
    var vpn: VPNSettings
    var logger: LoggerSettings
    var subscriber: SubscriberSettings
    var speedTest: SpeedTestSettings
    var httpCapture: CaptureSettings
    var networkActivity: NetworkActivitySettings
    var script: ScriptSettings
    var activeNodeId: String?
    var routeMode: RouteMode
}

enum RouteMode: String, Codable {
    case globalProxy    // 全局代理
    case rule            // 规则分流
    case globalDirect    // 全局直连
}
```

## 3.4 核心 API

```swift
final class ConfigManager {
    static let shared = ConfigManager()

    /// 启动时加载全部配置
    /// - Throws: 配置损坏且无法恢复时抛出
    func loadAll() throws

    /// 通用保存方法（加锁 + 原子写入）
    func save<T: ConfigFile>(_ config: T) throws

    /// 读取配置
    func load<T: ConfigFile>(_ type: T.Type) throws -> T

    /// 导出全部配置为 ZIP
    /// - Parameter secretMask: 是否脱敏密钥
    /// - Returns: ZIP 文件数据
    func exportAll(secretMask: Bool) throws -> Data

    /// 导入配置（覆盖当前）
    /// - Parameter data: ZIP 文件数据
    /// - Throws: 版本不兼容、文件损坏
    func importAll(data: Data) throws

    /// 恢复出厂设置
    /// - 自动备份当前配置到临时目录
    /// - 重置为默认值
    func resetToDefault() throws
}
```

## 3.5 版本迁移

每个配置文件头部包含 `version` 字段：

```json
{
  "version": "1.0.0",
  "data": { }
}
```

启动时迁移流程：

```
读取配置文件
    ↓
解析 version 字段
    ↓
版本 == 当前版本？ ──是──→ 直接加载
    ↓ 否
执行迁移脚本（按版本差逐级升级）
    ↓
补齐缺失字段，设置默认值
    ↓
保存迁移后配置
```

迁移脚本示例：

```swift
private func migrate(from oldVersion: String, to newVersion: String) throws {
    if oldVersion < "1.1.0" {
        // 1.0.0 → 1.1.0：新增字段
        config.newField = defaultValue
    }
}
```

## 3.6 并发保护

### 读写锁

```swift
final class ConfigManager {
    private let lock = NSLock()

    func save<T: ConfigFile>(_ config: T) throws {
        lock.lock()
        defer { lock.unlock() }
        // 写入逻辑
    }
}
```

### 原子写入

```
写入临时文件 config.json.tmp
    ↓
fsync 刷新磁盘
    ↓
rename 替换正式文件 config.json
    ↓
保证写入过程中断不会损坏正式文件
```

## 3.7 导入导出

### 导出流程

```
收集全部 JSON 配置
    ↓
可选脱敏：
    ├─ 节点 UUID → ********
    ├─ 订阅 URL → ********
    └─ 节点密钥 → ********
    ↓
打包为 ZIP
    ↓
附加版本信息
```

### 导入流程

```
读取 ZIP
    ↓
校验版本号
    ↓
备份当前配置到临时目录
    ↓
解压覆盖
    ↓
重新加载全部模块
    ↓
成功？ ──是──→ 通知 UI 刷新
    ↓ 否
回滚到备份
```

## 3.8 容错策略

| 异常场景 | 处理方式 |
| --- | --- |
| JSON 语法错误 | 加载最近备份文件 |
| 备份也损坏 | 使用默认配置，提示用户 |
| 磁盘空间不足 | 写入失败，记录 ERROR 日志 |
| 文件权限不足 | 提示用户检查应用沙盒 |
| 版本不兼容 | 尝试迁移，失败则提示重新配置 |
| 导入文件损坏 | 不覆盖现有配置，提示错误 |

## 3.9 与其他模块交互

- **面板 UI**：调用 `loadAll()`、`save()`、`importAll()`
- **VPN 模块**：读取 `vpn`、`activeNodeId`、`routeMode`
- **节点模块**：读写 `nodes.json`
- **订阅模块**：读写 `subscriptions.json`
- **日志模块**：记录配置操作日志
