# 03 - 配置管理模块

## 3.1 职责

- 统一读写 JSON 配置文件
- 配置版本迁移、升级兼容
- 配置打包导出 / 导入恢复
- 导出密钥脱敏选项
- 配置文件读写加锁，防止并发损坏
- 校验 JSON 语法，非法配置拦截

## 3.2 数据文件清单

| 文件 | 说明 |
| --- | --- |
| `config.json` | 全局应用设置（VPN、日志、订阅、UI 外观） |
| `nodes.json` | 节点列表、分组、标签、测速缓存 |
| `subscriptions.json` | 订阅源配置、meta 流量信息、过滤规则 |
| `rules.json` | 分流路由规则 |
| `rewrite.json` | MITM HTTP 重写规则 |
| `scripts.json` | JS 脚本配置 |
| `logs/` | 日志文件目录 |

## 3.3 核心 API

```swift
final class ConfigManager {
    static let shared = ConfigManager()

    /// 启动时加载全部配置
    func loadAll() throws

    /// 通用保存方法
    func save<T: Codable>(_ data: T, path: String) throws

    /// 导出全部配置
    /// - Parameter secretMask: 是否脱敏密钥
    func exportAll(secretMask: Bool) throws -> Data

    /// 导入配置
    func importAll(data: Data) throws

    /// 恢复出厂设置
    func resetToDefault() throws
}
```

## 3.4 版本迁移

每个配置文件头部包含 `version` 字段：

```json
{
  "version": "1.0.0",
  "data": { }
}
```

启动时读取版本号，与当前代码版本对比：

- 版本一致：直接加载
- 旧版本：执行迁移脚本，补齐缺失字段
- 无法识别：加载最近备份，提示用户

## 3.5 并发保护

- 读写操作使用 `NSLock` 加锁
- 写入采用临时文件 + 原子替换（先写 `.tmp`，再 `rename`）
- 防止并发写导致 JSON 损坏

## 3.6 导入导出

### 导出

打包为 ZIP，包含：

- 全部 JSON 配置
- CA 根证书（可选）
- 版本信息

导出时可选脱敏：

- 节点 UUID 替换为 `********`
- 订阅 URL 替换为 `********`
- CA 私钥不导出

### 导入

1. 读取 ZIP
2. 校验版本号
3. 备份当前配置到临时目录
4. 解压覆盖
5. 重新加载全部模块
6. 失败则回滚到备份

## 3.7 容错

- JSON 损坏：自动加载最近备份
- 备份也损坏：使用默认配置，提示用户
- 磁盘空间不足：写入失败，记录 ERROR 日志
- 文件权限不足：提示用户检查应用沙盒
