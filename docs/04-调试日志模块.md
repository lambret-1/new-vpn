# 04 - 调试日志模块

## 4.1 职责

- 分级日志输出
- 内存环形缓冲区（实时 UI 查看）
- 文件持久化滚动日志
- 敏感信息自动脱敏
- 日志检索、过滤、导出
- 接收 sing-box 内核日志（IPC 转发）
- 异步写入，不阻塞主代理链路

## 4.2 日志级别

| 级别 | rawValue | 用途 | 默认开关 |
| --- | --- | --- | --- |
| fatal | `fatal` | 程序崩溃、TUN 启动失败 | 永久开启 |
| error | `error` | 节点连接失败、脚本异常、订阅拉取失败 | 永久开启 |
| warn | `warn` | 证书异常、配置缺失、性能超限 | 开启 |
| info | `info` | 节点切换、订阅更新、模块加载 | 开启 |
| debug | `debug` | 流量匹配、事件触发、内核详细报文 | 关闭 |
| trace | `trace` | 完整四层连接、HTTP 原始报文 | 关闭 |

## 4.3 数据模型

```swift
enum LogLevel: String, Codable, Comparable {
    case fatal, error, warn, info, debug, trace
}

struct LogItem: Identifiable {
    let id: UUID
    let timestamp: Date
    let level: LogLevel
    let module: String       // 模块名
    let message: String
    let extra: [String: String]?  // 附加字段
    let stack: String?        // 异常堆栈（仅 error/fatal）
}
```

### module 枚举值

| 模块名 | 说明 |
| --- | --- |
| `kernel` | sing-box 内核 |
| `node` | 节点模块 |
| `subscription` | 订阅模块 |
| `route` | 分流模块 |
| `mitm` | MITM 模块 |
| `capture` | 抓包模块 |
| `networkActivity` | 网络活动模块 |
| `script` | JS 脚本 |
| `interpreter` | JS 解释器 |
| `config` | 配置模块 |
| `vpn` | VPN 模块 |

## 4.4 分层结构

```
业务模块 / 内核
    ↓ 调用 Logger.debug() 等
日志入口 API（同步调用，立即返回）
    ↓
异步队列（DispatchQueue，后台）
    ↓
日志处理器
    ├─ 内存环形缓冲区（供 UI 实时查看）
    └─ 文件持久化输出（滚动文件）
```

### 异步队列

- 主代理链路调用 `Logger.info()` 立即返回
- 日志入队，后台线程异步处理
- 队列容量：1000 条
- 队列满时丢弃 `trace` / `debug`
- 保留 `error` / `warn` / `info`

### 内存环形缓冲区

- 固定容量（默认 2000 条，可配置 500-5000）
- FIFO 淘汰旧日志
- 程序退出清空
- 支持增量推送给 UI（Combine / AsyncStream）

### 文件滚动

| 配置项 | 默认值 |
| --- | --- |
| 目录 | `app_data/logs/` |
| 单文件上限 | 5MB |
| 文件数量上限 | 10 个 |
| 命名格式 | `app-YYYYMMDD_NNN.log` |
| 触发滚动 | 文件大小超限 / 日期切换 |

## 4.6 核心 API

```swift
final class Logger {
    static let shared = Logger()

    func fatal(module: String, message: String, stack: String? = nil)
    func error(module: String, message: String, stack: String? = nil)
    func warn(module: String, message: String)
    func info(module: String, message: String)
    func debug(module: String, message: String, extra: [String: String]? = nil)
    func trace(module: String, message: String, extra: [String: String]? = nil)

    /// 获取内存日志（供 UI 查看）
    func getLogs(level: LogLevel?, module: String?, keyword: String?) -> [LogItem]

    /// 清空内存日志
    func clearMemoryLogs()

    /// 导出日志为文件
    func exportLogs(filter: LogFilter) throws -> URL
}
```

## 4.8 容错策略

| 异常 | 处理 |
| --- | --- |
| 文件写入失败（权限 / 磁盘满） | 关闭文件日志，保留内存日志，记录 WARN |
| 单条日志超长（>2048 字符） | 截断到 2048，附加 `...[截断]` |
| 高频日志涌入 | 队列溢出丢弃低级别，保护主链路 |
| 脱敏正则异常 | 跳过该条脱敏，原文输出，记录 WARN |

## 4.9 与其他模块交互

- **全部模块**：调用 `Logger.info()` 等输出日志
- **VPN 模块**：接收 IPC 转发的内核日志，归属 `kernel` 模块
- **JS 脚本**：`console.log` 桥接到 `script` 模块日志
- **面板 UI**：订阅内存缓冲区增量事件，实时刷新日志列表
- **配置模块**：读写日志配置项
