# 04 - 调试日志模块

## 4.1 职责

- 分级日志输出
- 内存环形缓冲区（实时 UI 查看）
- 文件持久化滚动日志
- 敏感信息自动脱敏
- 日志检索、过滤、导出
- 接收 sing-box 内核日志（IPC 转发）

## 4.2 日志级别

| 级别 | 说明 | 默认开关 |
| --- | --- | --- |
| fatal | 程序崩溃、TUN 启动失败 | 永久开启 |
| error | 节点连接失败、脚本异常、订阅拉取失败 | 永久开启 |
| warn | 证书异常、配置缺失、性能超限 | 开启 |
| info | 节点切换、订阅更新、模块加载 | 开启 |
| debug | 流量匹配、事件触发、内核详细报文 | 关闭 |
| trace | 完整四层连接、HTTP 原始报文 | 关闭 |

## 4.3 数据模型

```swift
enum LogLevel: String, Codable {
    case fatal, error, warn, info, debug, trace
}

struct LogItem: Identifiable {
    let id: UUID
    let timestamp: Date
    let level: LogLevel
    let module: String
    let message: String
    let extra: [String: String]?
    let stack: String?
}
```

### module 枚举

- `kernel`：sing-box 内核
- `node`：节点模块
- `subscription`：订阅模块
- `route`：分流模块
- `mitm`：MITM 模块
- `capture`：抓包模块
- `networkActivity`：网络活动模块
- `script`：JS 脚本
- `interpreter`：JS 解释器
- `config`：配置模块
- `vpn`：VPN 模块

## 4.4 分层结构

```
业务模块 / 内核 → 日志入口 API → 异步队列 → 日志处理器
                                        ├─ 内存环形缓冲区（UI 实时查看）
                                        └─ 文件持久化输出（滚动文件）
```

### 异步队列

- 日志写入后台队列，主代理链路不阻塞
- 队列满时丢弃 trace / debug 级别
- 保留 error / warn / info

### 内存环形缓冲区

- 固定容量（默认 2000 条，可配置 500-5000）
- FIFO 淘汰旧日志
- 程序退出清空
- 支持增量推送给 UI

### 文件滚动

- 目录：`app_data/logs/`
- 单文件上限：默认 5MB
- 文件数量上限：默认 10 个
- 命名：`app-20260923_001.log`
- 超出自动删除最旧文件

## 4.6 配置项

```json
"logger": {
  "level": "info",
  "memoryBufferCount": 2000,
  "enableFileLog": true,
  "maxFileSizeMB": 5,
  "maxFileCount": 10,
  "maskSecret": true
}
```

## 4.7 容错

- 文件写入失败：关闭文件日志，保留内存日志
- 单条日志超长（>2048 字符）：截断
- 高频日志：队列溢出丢弃低级别，保护主链路
