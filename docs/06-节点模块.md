# 06 - 节点模块

## 6.1 职责

- 节点 CRUD
- 分组、标签管理
- vmess / vless 链接解析
- 订阅增量同步（接收订阅解释器输出）
- 为 VPN 模块输出 sing-box 出站配置片段
- 管理测速结果缓存
- 订阅更新时保留用户本地分组、标签、备注

## 6.2 数据模型

```swift
struct NodeModel: Identifiable, Codable {
    let id: String                    // UUID，主键
    var name: String                  // 节点名称
    var protocolType: ProtocolType    // vless / vmess
    var host: String                  // 服务器地址
    var port: Int                     // 端口
    var uuid: String                  // 用户 UUID
    var alterId: Int                  // vmess alterId
    var security: String              // vmess 加密方式
    var transport: TransportConfig
    var tls: TLSConfig
    var group: String                 // 分组名称
    var tags: [String]                // 标签
    var remark: String                 // 备注
    var sourceType: NodeSourceType    // 来源
    var subSourceId: String?          // 订阅来源 ID
    var lastSpeedResult: SpeedResult? // 最近测速结果
}

enum ProtocolType: String, Codable {
    case vless
    case vmess
}

enum NodeSourceType: String, Codable {
    case manual          // 手动添加
    case subscription    // 订阅导入
}

struct TransportConfig: Codable {
    var type: TransportType          // tcp / ws
    var path: String?                 // ws path
    var host: String?                 // ws Host 头
    var headers: [String: String]?   // 额外请求头
}

enum TransportType: String, Codable {
    case tcp
    case ws
}

struct TLSConfig: Codable {
    var enable: Bool
    var serverName: String?          // SNI
    var reality: Bool                 // 是否 Reality
    var publicKey: String?            // Reality 公钥
    var shortId: String?              // Reality shortId
    var fingerprint: String?         // uTLS 指纹
}
```

## 6.3 链接解析

### vless:// 格式

```
vless://uuid@host:port?encryption=none&type=ws&path=%2Fws&host=example.com&security=tls&sni=example.com#备注名称
```

解析字段映射：

| URL 部分 | 对应字段 |
| --- | --- |
| 用户信息段 | `uuid` |
| host | `host` |
| port | `port` |
| `encryption` | 固定 `none`（vless） |
| `type` | `transport.type` |
| `path` | `transport.path` |
| `host` (query) | `transport.host` |
| `security` | `tls.enable` |
| `sni` | `tls.serverName` |
| `pbk` | `tls.publicKey`（Reality） |
| `sid` | `tls.shortId`（Reality） |
| `fp` | `tls.fingerprint` |
| 锚点（`#` 后） | `name` |

### vmess:// 格式

```
vmess://base64(json)
```

Base64 解码后 JSON 字段映射：

| JSON 字段 | 对应属性 |
| --- | --- |
| `ps` | `name` |
| `add` | `host` |
| `port` | `port` |
| `id` | `uuid` |
| `aid` | `alterId` |
| `net` | `transport.type` |
| `host` | `transport.host` |
| `path` | `transport.path` |
| `tls` | `tls.enable` |
| `sni` | `tls.serverName` |

## 6.4 订阅增量同步

订阅解释器输出 `[RawNodeModel]`，节点模块执行：

```
接收 rawNodeList + subId
    ↓
遍历 rawNodeList
    ↓
匹配键：protocolType + host + port
    ↓
本地已存在？
    ├─ 是 → 更新远程参数
    │       ↓
    │     保留本地 group、tags、remark
    │
    └─ 否 → 新增节点
            ↓
          生成本地 UUID
          sourceType = .subscription
          subSourceId = subId
          group = 默认分组
    ↓
清理旧订阅节点（按配置选项）
    ├─ 自动删除：删除 sourceType=subscription 且 subSourceId=subId 且不在新列表中的节点
    └─ 保留：不删除旧节点
```

      "Host": "hk.example.com"

## 6.6 分组与标签

- 内置默认分组「默认分组」，不可删除、不可重命名
- 用户自定义分组：新增、重命名、删除
- 删除分组时节点自动迁移至「默认分组」
- 节点可多标签
- 支持按分组折叠展示
- 支持按标签筛选

## 6.7 核心 API

```swift
final class NodeManager {
    static let shared = NodeManager()

    /// 加载节点列表
    func loadNodes() throws

    /// 获取全部节点
    func getAllNodes() -> [NodeModel]

    /// 获取节点（按 ID）
    func getNode(id: String) -> NodeModel?

    /// 新增节点
    func addNode(_ node: NodeModel) throws

    /// 更新节点
    func updateNode(_ node: NodeModel) throws

    /// 删除节点
    /// - 删除正在使用的节点时自动清空 activeNodeId
    func deleteNode(id: String) throws

    /// 批量导入链接
    /// - Parameter links: 多行 vmess:// / vless:// 链接
    /// - Returns: 成功数量、失败条目列表
    func importLinks(_ links: String) throws -> (success: Int, failed: [(line: String, error: String)])

    /// 订阅增量同步
    func syncSubscriptionNodes(_ rawList: [RawNodeModel], subId: String, removeOrphans: Bool) throws

    /// 渲染出站配置
    func renderOutbound(nodeId: String) throws -> [String: Any]

    /// 设置当前活跃节点
    func setActiveNode(_ nodeId: String) throws

    /// 获取当前活跃节点
    func getActiveNode() -> NodeModel?
}
```

## 6.8 容错策略

| 异常 | 处理 |
| --- | --- |
| 链接解析失败 | 跳过坏链接，收集错误，不中断批量导入 |
| 订阅更新解析异常 | 跳过异常节点，其余正常入库 |
| 删除正在使用的节点 | 自动清空 activeNodeId，切换直连，UI 弹窗提醒 |
| nodes.json 损坏 | 加载最近备份，提示用户 |
| UUID 格式校验失败 | 拒绝保存，提示错误 |
| 端口越界（1-65535） | 拒绝保存，提示错误 |

## 6.9 与其他模块交互

- **VPN 模块**：提供出站配置片段
- **订阅管理器**：接收增量同步数据
- **测速模块**：读写 `lastSpeedResult`
- **面板 UI**：提供节点列表数据
- **配置模块**：读写 `nodes.json`
