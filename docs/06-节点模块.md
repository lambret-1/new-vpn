# 06 - 节点模块

## 6.1 职责

- 节点 CRUD
- 分组、标签管理
- vmess / vless 链接解析
- 订阅增量同步（接收订阅解释器输出）
- 为 VPN 模块输出 sing-box 出站配置片段
- 管理测速结果缓存
- 订阅更新时保留用户本地分组、标签、备注

## 6.2 数据模型

```swift
struct NodeModel: Identifiable, Codable {
    let id: String
    var name: String
    var protocolType: String       // vless / vmess
    var host: String
    var port: Int
    var uuid: String
    var alterId: Int              // vmess
    var security: String          // vmess
    var transport: TransportConfig
    var tls: TLSConfig
    var group: String
    var tags: [String]
    var remark: String
    var sourceType: NodeSourceType // manual / subscription
    var subSourceId: String?
    var lastSpeedResult: SpeedResult?
}

enum NodeSourceType: String, Codable {
    case manual
    case subscription
}

struct TransportConfig: Codable {
    var type: String              // tcp / ws
    var path: String?
    var host: String?
}

struct TLSConfig: Codable {
    var enable: Bool
    var serverName: String?
    var reality: Bool
    var publicKey: String?
    var shortId: String?
}
```

## 6.3 链接解析

### vless:// 格式

```
vless://uuid@host:port?encryption=none&type=ws&path=%2Fws&host=example.com&security=tls&sni=example.com#备注名称
```

解析字段：

- URL 主体：uuid、host、port
- Query：encryption、type、path、host、security、sni
- 锚点（# 后）：备注名称

### vmess:// 格式

```
vmess://base64(json)
```

Base64 解码后为 JSON：

```json
{
  "v": "2",
  "ps": "备注名称",
  "add": "服务器地址",
  "port": "443",
  "id": "uuid",
  "aid": 0,
  "net": "ws",
  "type": "none",
  "host": "",
  "path": "/path",
  "tls": "tls",
  "sni": ""
}
```

## 6.4 订阅增量同步

订阅解释器输出 `[RawNodeModel]`，节点模块执行：

1. 匹配：`协议 + host + port` 判定为同一节点
2. 新增：生成本地 UUID，标记 `sourceType = subscription`，绑定 `subSourceId`
3. 更新：更新远程参数，**保留本地 group、tags、remark**
4. 旧节点：按订阅配置选项自动删除 / 保留

## 6.5 出站配置渲染

将选中节点转换为 sing-box outbound JSON：

```json
{
  "type": "vless",
  "tag": "proxy",
  "server": "hk.example.com",
  "server_port": 443,
  "uuid": "xxx",
  "tls": {
    "enabled": true,
    "server_name": "hk.example.com",
    "reality": {
      "enabled": false
    }
  },
  "transport": {
    "type": "ws",
    "path": "/path",
    "headers": {
      "Host": "hk.example.com"
    }
  }
}
```

## 6.6 分组与标签

- 内置默认分组「默认分组」，不可删除
- 用户自定义分组：新增、重命名、删除
- 删除分组时节点迁移至默认分组
- 节点可多标签
- 支持按分组折叠展示

## 6.8 容错

- 链接解析失败：跳过坏链接，记录错误
- 订阅更新解析异常：跳过异常节点，其余正常入库
- 删除正在使用的节点：自动清空 activeNodeId，切换直连
- nodes.json 损坏：加载最近备份
