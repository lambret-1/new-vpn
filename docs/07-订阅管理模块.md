# 07 - 订阅管理模块

## 7.1 职责

- 订阅源 CRUD
- 持久化 `subscriptions.json`
- 定时自动更新任务调度
- 手动触发更新，调用订阅解释器
- 保存上次更新时间、状态、meta 流量信息
- 展示流量、到期信息给 UI

## 7.2 数据模型

```swift
struct Subscription: Identifiable, Codable {
    let id: String                    // UUID
    var name: String                  // 订阅名称
    var url: String                   // 订阅 URL
    var enable: Bool                  // 是否启用
    var autoUpdate: Bool              // 是否自动更新
    var updateIntervalMin: Int        // 更新间隔（分钟）
    var lastUpdateTime: Date?         // 上次更新时间
    var lastUpdateStatus: UpdateStatus // 上次更新状态
    var lastErrorMessage: String?     // 上次错误信息
    var metaInfo: SubscriptionMetaInfo
    var filterRule: SubscriptionFilterRule
    var keepNodesAfterDelete: Bool   // 删除订阅时是否保留节点
}

enum UpdateStatus: String, Codable {
    case success
    case fail
    case pending
    case neverUpdated
}

struct SubscriptionMetaInfo: Codable {
    var totalTrafficBytes: Int64     // 总流量
    var usedTrafficBytes: Int64       // 已用流量
    var expireTimestamp: Int64        // 到期时间戳（0 = 无）

    /// 剩余流量
    var remainingBytes: Int64 { totalTrafficBytes - usedTrafficBytes }

    /// 是否过期
    var isExpired: Bool {
        guard expireTimestamp > 0 else { return false }
        return Date().timeIntervalSince1970 > Double(expireTimestamp)
    }
}

struct SubscriptionFilterRule: Codable {
    var excludeProtocol: [String]      // 排除协议
    var excludeKeyword: [String]        // 排除关键词
    var onlyIncludeKeyword: [String]   // 只包含关键词
}
```

## 7.3 定时更新机制

```
程序启动
    ↓
加载全部订阅源
    ↓
遍历启用自动更新的订阅
    ↓
计算下次更新时间 = lastUpdateTime + updateIntervalMin
    ↓
当前时间 >= 下次更新时间？
    ├─ 是 → 触发后台更新
    └─ 否 → 设置定时器等待
    ↓
定时器触发
    ↓
调用订阅解释器拉取解析
    ↓
成功 → 更新 lastUpdateTime / status / metaInfo
    ↓
调用节点模块增量同步
    ↓
失败 → 更新 status = fail，记录错误
    ↓
重新计算下次更新时间
```

### 定时任务规则

- 后台队列执行，不阻塞 UI
- 多个订阅源可并发更新（最多 2 个）
- 程序退出停止定时任务
- 自动更新失败不弹窗，仅写日志
- 自动更新完成不自动触发测速

## 7.4 手动更新流程

```
UI 点击「立即更新」
    ↓
状态 → pending
    ↓
调用订阅解释器
    ↓
成功 → 提示成功，显示解析统计
    │       解析 N 个节点，新增 M 个，过滤 K 个
    ↓
失败 → 弹窗显示错误
    │       网络超时 / HTTP 403 / 内容格式错误
    ↓
更新 lastUpdateTime / status
```

## 7.5 删除订阅两种模式

### 模式 A：保留节点

- 只删除订阅源配置
- 保留已导入节点
- 节点自动变为 `sourceType = manual`
- 适用：想保存节点，不再自动更新

### 模式 B：删除节点

- 删除订阅源
- 删除全部来自该订阅的节点
- 适用：彻底清理

## 7.6 核心 API

```swift
final class SubscriptionManager {
    static let shared = SubscriptionManager()

    /// 加载订阅列表
    func loadSubscriptions() throws

    /// 获取全部订阅
    func getAllSubscriptions() -> [Subscription]

    /// 新增订阅
    func addSubscription(_ sub: Subscription) throws

    /// 更新订阅
    func updateSubscription(_ sub: Subscription) throws

    /// 删除订阅
    /// - Parameters:
    ///   - id: 订阅 ID
    ///   - keepNodes: 是否保留已导入节点
    func deleteSubscription(id: String, keepNodes: Bool) throws

    /// 手动更新单个订阅
    func refreshSubscription(id: String) async throws -> SubParseResult

    /// 全部更新
    func refreshAll() async

    /// 启动定时任务
    func startAutoUpdateTimer()

    /// 停止定时任务
    func stopAutoUpdateTimer()
}
```

## 7.7 配置项

```json
"subscriber": {
  "fetchUseProxy": false,
  "httpTimeoutSec": 30,
  "maxRawContentSizeBytes": 2097152
}
```

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `fetchUseProxy` | false | 拉取订阅是否走当前代理（防止死锁） |
| `httpTimeoutSec` | 30 | HTTP 请求超时 |
| `maxRawContentSizeBytes` | 2097152 | 订阅内容最大限制（2MB） |

## 7.8 容错策略

| 异常 | 处理 |
| --- | --- |
| 网络超时 | 返回失败，保留旧节点 |
| HTTP 403 / 404 | 返回失败，显示错误信息 |
| 订阅内容为空 | 解析成功但节点列表为空，提示 |
| 订阅内容过大 | 超过大小上限直接终止 |
| 定时任务异常 | 捕获异常，下次定时器继续 |
| 删除正在使用的订阅 | 节点保留，隧道不中断 |

## 7.9 与其他模块交互

- **订阅解释器**：调用拉取解析
- **节点模块**：增量同步节点
- **配置模块**：读写 `subscriptions.json`
- **日志模块**：记录订阅操作日志
- **面板 UI**：展示订阅列表、流量、更新状态
