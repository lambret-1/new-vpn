# 08 - 订阅解释器

## 8.1 职责

- HTTP 拉取订阅文本
- Base64 自动识别 + 容错解码
- 分行处理，注释行提取流量 / 过期元信息
- 识别 `vmess://` / `vless://` 链接
- 单链接解析，输出 `RawNodeModel`
- 过滤规则执行
- 收集解析失败行

> 只负责解析，不操作持久化存储。输出交给订阅管理器 → 节点模块增量同步。

## 8.2 整体流程

```
HTTP GET 订阅 URL
    ↓ 超时 30s，大小限制 2MB
获取原始响应文本
    ↓
Base64 检测 & 解码
    ↓ 自动识别明文 / Base64
分行处理（按 \n 分割）
    ↓
遍历每一行：
    ├─ 空行 → 跳过
    ├─ 注释行（# 开头）→ 提取 meta 信息
    ├─ vmess:// → 解析节点
    ├─ vless:// → 解析节点
    └─ 其他 → 记录为失败行
    ↓
过滤规则执行（excludeProtocol / excludeKeyword）
    ↓
输出 SubParseResult
```

## 8.3 数据模型

```swift
struct SubParseResult {
    let success: Bool
    let rawContent: String           // 原始响应文本
    let metaInfo: SubscriptionMetaInfo
    let parsedNodeList: [RawNodeModel]
    let failItems: [SubParseFailItem]
    let parseTimeMs: Int             // 解析耗时
}

struct RawNodeModel {
    let protocolType: String
    let host: String
    let port: Int
    let uuid: String
    let alterId: Int?
    let security: String?
    let transportType: String?
    let path: String?
    let wsHost: String?
    let tlsEnable: Bool
    let sni: String?
    let reality: Bool
    let publicKey: String?
    let shortId: String?
    let remark: String
}

struct SubParseFailItem {
    let rawLine: String
    let errorMsg: String
    let lineNumber: Int
}
```

## 8.4 Base64 解码

### 检测逻辑

```
去除换行、空格
    ↓
判断字符集合是否符合 Base64 字符集（A-Za-z0-9+/=）
    ↓
尝试 Base64 解码
    ↓
解码成功？
    ├─ 是 → 使用解码后明文
    └─ 否 → 判定为明文，直接使用原始 body
```

### 容错处理

| 问题 | 处理方式 |
| --- | --- |
| 缺失 `=` 填充 | 自动补齐到 4 的倍数 |
| URL Safe Base64 | `-` → `+`，`_` → `/` |
| 换行混杂 | 先去除所有换行再解码 |
| 混合编码 | 尝试多次解码，取第一次成功结果 |

## 8.5 注释行 Meta 解析

常见订阅格式：

```
# upload: 10GB
# download: 90GB
# total: 100GB
# expire: 2026-12-31
```

正则匹配规则（宽松匹配）：

| 正则 | 提取字段 |
| --- | --- |
| `total|流量|总流量\s*[:：]\s*(.+)` | `totalTrafficBytes` |
| `used|已用|download|upload\s*[:：]\s*(.+)` | `usedTrafficBytes` |
| `expire|到期|过期\s*[:：]\s*(.+)` | `expireTimestamp` |

流量单位转换：

```
KB → × 1024
MB → × 1024 × 1024
GB → × 1024 × 1024 × 1024
TB → × 1024^4
```

解析不到则置 0。

## 8.6 链接解析

### vmess:// 解析

```
去掉 "vmess://" 前缀
    ↓
Base64 解码
    ↓
JSON 反序列化
    ↓
字段映射 → RawNodeModel
    ↓
字段校验：host 非空、端口有效
```

### vless:// 解析

```
去掉 "vless://" 前缀
    ↓
URL 解析
    ↓
用户信息部分 → uuid
    ↓
host、port
    ↓
Query 参数解析：
    ├─ encryption
    ├─ type → transportType
    ├─ path
    ├─ host → wsHost
    ├─ security → tlsEnable
    ├─ sni → sni
    ├─ pbk → publicKey
    ├─ sid → shortId
    └─ fp → fingerprint
    ↓
锚点（# 后）→ remark
```

## 8.7 过滤规则

对解析成功的节点列表执行：

```
遍历 parsedNodeList
    ↓
1. excludeProtocol：
    节点协议在排除列表中？→ 剔除
    ↓
2. excludeKeyword：
    节点名称包含关键词？→ 剔除
    ↓
3. onlyIncludeKeyword：
    节点名称不包含任何保留关键词？→ 剔除
    ↓
输出过滤后列表
```

## 8.8 容错策略

| 异常 | 处理 |
| --- | --- |
| 单条节点损坏 | 记入 failItems，继续解析剩余行 |
| Base64 解码失败 | 判定为明文，继续解析 |
| 网络超时 | 返回失败结果，不解析 |
| HTTP 4xx / 5xx | 返回失败结果，记录状态码 |
| 订阅内容为空 | 解析成功但节点列表为空 |
| 超大订阅 | 超过大小上限直接终止 |
| JSON 解析失败（vmess） | 记录为失败行，跳过 |

## 8.9 支持协议

| 协议 | 支持 | 处理方式 |
| --- | --- | --- |
| vmess:// | ✅ | 完整解析 |
| vless:// | ✅ | 完整解析 |
| trojan:// | ❌ | 过滤忽略 |
| ss:// | ❌ | 过滤忽略 |
| ssr:// | ❌ | 过滤忽略 |
| http:// / socks:// | ❌ | 过滤忽略 |

## 8.10 核心 API

```swift
final class SubscriptionParser {
    static let shared = SubscriptionParser()

}
```
