# 09 - 测速模块

## 9.1 职责

- 对节点执行测速
- 单节点测速 / 批量节点测速
- 测速结果缓存存入 nodes.json
- 图表数据输出给 UI
- 超时、网络异常处理

## 9.2 测速指标

| 指标 | 说明 |
| --- | --- |
| 延迟（Latency） | 隧道内 HTTP 回包耗时 |
| 抖动（Jitter） | 多次延迟差值 |
| 丢包率（Loss） | 连续探测丢包百分比 |
| 上行带宽（Upload） | 最大上传速率 Mbps |
| 下行带宽（Download） | 最大下载速率 Mbps |

## 9.3 测速原理

### 延迟测试

- 通过代理隧道发送 HTTP HEAD 请求
- 小数据包，毫秒级精度
- 多次探测计算平均值
- 三次重试过滤异常极值

### 带宽测试

- 固定大小测试文件拉取（默认 10MB）
- 计算瞬时峰值与平均速率
- 上传同理（默认 5MB）

### 链路隔离

- 测速独立协程、独立隧道实例
- **不占用当前代理连接**
- 测速过程不影响正在使用的网络

## 9.4 数据模型

```swift
struct SpeedResult: Codable {
    var latencyMs: Int           // 延迟
    var jitterMs: Int            // 抖动
    var lossPercent: Double      // 丢包率 %
    var downloadMbps: Double      // 下行 Mbps
    var uploadMbps: Double         // 上行 Mbps
    var testTime: Date
}
```

## 9.5 批量测速

- 后台静默测速
- 最多同时 3 个节点并发
- 完成后自动按延迟排序
- 自动标记：最优节点、可用节点、失效节点

## 9.6 缓存策略

- 测速结果本地缓存 5 分钟
- 短时间重复点击不重复测速
- 订阅更新成功后清空该批节点缓存
- 后台测速自动限流

## 9.7 核心 API

```swift
final class SpeedTestManager {
    static let shared = SpeedTestManager()

    /// 单节点测速
    func testNode(nodeId: String) async throws -> SpeedResult

    /// 批量测速
    func testNodes(nodeIds: [String], onProgress: @escaping (Int, Int) -> Void) async

    /// 获取缓存
    func getCachedResult(nodeId: String) -> SpeedResult?
}
```

## 9.8 超时与容错

| 项目 | 默认值 |
| --- | --- |
| 握手超时 | 3s |
| 延迟探测超时 | 5s |
| 带宽测速超时 | 15s |
| 网络波动重试 | 2 次 |

## 9.9 配置项

```json
"speedTest": {
  "cacheTtlMin": 5,
  "maxConcurrentTest": 3,
  "downloadSizeMB": 10,
  "uploadSizeMB": 5
}
```
