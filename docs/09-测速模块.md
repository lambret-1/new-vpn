# 09 - 测速模块

## 9.1 职责

- 对节点执行测速
- 单节点测速 / 批量节点测速
- 测速结果缓存存入节点模型
- 图表数据输出给 UI
- 超时、网络异常处理

## 9.2 测速指标

| 指标 | 单位 | 说明 |
| --- | --- | --- |
| 延迟（Latency） | ms | 隧道内 HTTP 回包耗时 |
| 抖动（Jitter） | ms | 多次延迟差值平均值 |
| 丢包率（Loss） | % | 连续探测丢包百分比 |
| 上行带宽（Upload） | Mbps | 最大上传速率 |
| 下行带宽（Download） | Mbps | 最大下载速率 |

## 9.3 测速原理

### 延迟测试

```
通过代理隧道建立 HTTP 连接
    ↓
发送 HEAD 请求（小数据包，~100 字节）
    ↓
记录响应时间
    ↓
重复 5 次
    ↓
取中位数作为延迟
    ↓
计算相邻差值平均值作为抖动
    ↓
失败次数 / 总次数 = 丢包率
```

### 带宽测试

```
下载测试：
    通过代理隧道下载固定大小文件（默认 10MB）
    ↓
计算总耗时
    ↓
速率 = 文件大小 × 8 / 耗时 / 1000000（Mbps）

上传测试：
    通过代理隧道上传固定大小数据（默认 5MB）
    ↓
计算总耗时
    ↓
速率 = 数据大小 × 8 / 耗时 / 1000000（Mbps）
```

### 链路隔离

- 测速使用独立临时隧道实例
- **不占用当前正在使用的代理连接**
- 测速过程不影响正在进行的网络活动

## 9.4 数据模型

```swift
struct SpeedResult: Codable {
    var latencyMs: Int          // 延迟（ms）
    var jitterMs: Int           // 抖动（ms）
    var lossPercent: Double     // 丢包率（%）
    var downloadMbps: Double    // 下行带宽（Mbps）
    var uploadMbps: Double       // 上行带宽（Mbps）
    var testTime: Date          // 测试时间
    var isSuccessful: Bool       // 是否成功
    var errorMessage: String?   // 失败原因
}
```

## 9.5 批量测速

```
接收节点 ID 列表
    ↓
并发限制：最多 3 个同时测速
    ↓
逐个测速：
    ├─ 启动临时隧道
    ├─ 延迟测试
    ├─ 带宽测试
    ├─ 销毁临时隧道
    └─ 回调进度
    ↓
全部完成
    ↓
按延迟排序
    ↓
标记节点状态：
    ├─ 延迟 < 100ms → 优秀
    ├─ 延迟 100-300ms → 良好
    ├─ 延迟 > 300ms → 较差
    └─ 失败 → 不可用
```

## 9.6 缓存策略

- 测速结果保存在节点模型的 `lastSpeedResult` 字段
- 缓存有效期：5 分钟（可配置）
- 短时间重复测速直接返回缓存结果
- 订阅更新成功后，清空该批节点的测速缓存
- 手动强制测速可跳过缓存

## 9.7 超时与容错

| 测试阶段 | 超时时间 | 重试次数 |
| --- | --- | --- |
| 隧道握手 | 3s | 1 |
| 延迟探测 | 5s | 2 |
| 带宽下载 | 15s | 0 |
| 带宽上传 | 15s | 0 |

失败处理：

- 隧道握手失败 → 标记节点不可用
- 延迟超时 → 延迟设为 -1，继续带宽测试
- 带宽超时 → 带宽设为 0
- 全部失败 → `isSuccessful = false`

## 9.8 核心 API

```swift
final class SpeedTestManager {
    static let shared = SpeedTestManager()

    /// 单节点测速
    /// - Parameters:
    ///   - nodeId: 节点 ID
    ///   - forceRefresh: 是否跳过缓存
    /// - Returns: 测速结果
    func testNode(nodeId: String, forceRefresh: Bool = false) async throws -> SpeedResult

    /// 批量测速
    /// - Parameters:
    ///   - nodeIds: 节点 ID 列表
    ///   - onProgress: 进度回调（当前序号、总数、当前节点、结果）
    func testNodes(
        nodeIds: [String],
        onProgress: @escaping (Int, Int, String, SpeedResult) -> Void
    ) async

    /// 获取缓存结果
    func getCachedResult(nodeId: String) -> SpeedResult?
}
```

## 9.10 与其他模块交互

- **节点模块**：读写 `lastSpeedResult`
- **VPN 模块**：创建临时隧道实例
- **配置模块**：读写测速配置
- **日志模块**：记录测速过程日志
- **面板 UI**：展示测速进度、结果图表
