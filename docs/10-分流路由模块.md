# 10 - 分流路由模块

## 10.1 职责

- 分流规则 CRUD
- 调整规则优先级
- 域名 / IP / IP-CIDR 规则匹配
- 出站策略（代理 / 直连 / 拒绝）
- 输出 sing-box 规则片段
- 支持热重载

## 10.2 三种全局模式

| 模式 | 说明 |
| --- | --- |
| 全局代理 | 所有流量走代理，自定义规则优先 |
| 规则分流（推荐） | 国内直连、国外代理、广告拒绝 |
| 全局直连 | 全部直连，仅自定义强制代理规则生效 |

## 10.3 规则匹配类型

### 域名类

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| domain | 精确匹配 | `baidu.com` |
| domain_suffix | 后缀匹配 | `.baidu.com` |
| domain_keyword | 关键词 | `baidu` |
| domain_regex | 正则 | `.*\.com$` |

### IP 类

| 类型 | 说明 |
| --- | --- |
| ip_cidr | IP 段 |
| ip_is_private | 内网私有 IP |

### 其他

- port / port_range
- network（tcp / udp）
- protocol（dns / http / tls）

## 10.4 出站策略

| 标签 | 说明 |
| --- | --- |
| proxy | 走代理节点 |
| direct | 直连 |
| block | 拒绝 / 丢弃 |

## 10.5 数据模型

```swift
struct RouteRule: Identifiable, Codable {
    let id: String
    var name: String
    var enable: Bool
    var matchType: String
    var matchValue: String
    var action: String              // proxy / direct / block
    var enableMitm: Bool          // 是否启用 MITM
    var remark: String
    var priority: Int               // 越小越先匹配
}

struct BuiltinRuleSet: Codable {
    let tag: String
    var enable: Bool
    let remoteUrl: String
    var autoUpdate: Bool
}
```

## 10.6 内置规则集

| 规则集 | 说明 | 默认出站 |
| --- | --- | --- |
| geosite-cn | 国内网站域名 | direct |
| geoip-cn | 国内 IP 段 | direct |
| category-ads-all | 广告域名 | block |
| private | 内网私有 IP | direct |

### 规则集更新

- 支持远程 SRS 格式
- 自动更新周期可配置
- 拉取失败保留旧缓存
- 直连下载，避免死锁

## 10.7 优先级

```
用户自定义规则（从上到下） > 远程规则集 > 内置规则 > 默认出站
```

UI 支持拖拽排序自定义规则。

## 10.8 DNS 分流

配套 DNS 路由：

- 内网 DNS → 直连本地 DNS
- 国内域名 DNS → 直连国内 DNS
- 代理域名 DNS → 通过代理远端 DNS
- TUN 53 端口 UDP 流量劫持到内置 DNS

## 10.9 热重载

- 修改分流规则 → 热重载 route 配置
- 已建立 TCP 连接沿用旧路由
- 新连接使用新规则
- 无需重启 TUN

## 10.10 核心 API

```swift
final class RouteRuleManager {
    static let shared = RouteRuleManager()

    func loadRules() throws
    func addRule(_ rule: RouteRule) throws
    func updateRule(_ rule: RouteRule) throws
    func deleteRule(id: String) throws
    func moveRule(id: String, to index: Int) throws
    func renderRules() throws -> [[String: Any]]
    func reloadRules() async throws
}
```
