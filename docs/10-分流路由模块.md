# 10 - 分流路由模块

## 10.1 职责

- 分流规则 CRUD
- 规则优先级管理
- 域名 / IP / IP-CIDR 规则匹配
- 出站策略（代理 / 直连 / 拒绝）
- 输出 sing-box 规则片段
- 支持热重载

## 10.2 三种全局模式

| 模式 | 说明 | 规则执行 |
| --- | --- | --- |
| 全局代理 | 所有流量走代理 | 自定义规则优先 |
| 规则分流（推荐） | 国内直连、国外代理、广告拒绝 | 完整规则链 |
| 全局直连 | 全部直连 | 仅强制代理规则生效 |

## 10.3 规则匹配类型

### 域名类

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `domain` | 精确匹配 | `baidu.com` |
| `domain_suffix` | 后缀匹配 | `.baidu.com`（最常用） |
| `domain_keyword` | 包含关键词 | `baidu` |
| `domain_regex` | 正则匹配 | `.*\.com$` |

### IP 类

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `ip_cidr` | IP 段 | `192.168.0.0/16` |
| `ip_is_private` | 内网私有 IP | 自动识别 |
| `source_ip` | 来源 IP | `10.0.0.0/8` |

### 其他条件

| 类型 | 说明 |
| --- | --- |
| `port` | 目标端口 |
| `port_range` | 端口范围 |
| `network` | tcp / udp |
| `protocol` | dns / http / tls（基于嗅探） |

## 10.4 出站策略

| 标签 | 说明 |
| --- | --- |
| `proxy` | 走代理节点 |
| `direct` | 直连 |
| `block` | 拒绝 / 丢弃 |

## 10.5 数据模型

```swift
struct RouteRule: Identifiable, Codable {
    let id: String
    var name: String
    var enable: Bool
    var matchType: MatchType
    var matchValue: String
    var action: RouteAction
    var enableMitm: Bool
    var remark: String
    var priority: Int  // 越小越先匹配
}

enum MatchType: String, Codable {
    case domain
    case domainSuffix
    case domainKeyword
    case domainRegex
    case ipCidr
    case ipIsPrivate
    case port
    case portRange
    case network
    case protocol
}

enum RouteAction: String, Codable {
    case proxy
    case direct
    case block
}

struct BuiltinRuleSet: Codable {
    let tag: String
    var enable: Bool
    let remoteUrl: String
    var autoUpdate: Bool
    var lastUpdateTime: Date?
    var version: String?
}
```

## 10.6 内置规则集

| 规则集 | 说明 | 默认出站 |
| --- | --- | --- |
| geosite-cn | 国内网站域名 | direct |
| geoip-cn | 国内 IP 段 | direct |
| category-ads-all | 广告域名 | block |
| private | 内网私有 IP | direct |

### 规则集更新

- 格式：SRS（sing-box Rule Set）
- 支持远程 URL 自动下载
- 自动更新周期可配置
- 拉取失败保留旧缓存
- 直连下载，避免死锁

## 10.7 优先级

```
匹配顺序（从上到下）：
1. 用户自定义规则（按 priority 排序）
2. 远程规则集（按启用顺序）
3. 内置规则集
4. 默认出站（由全局模式决定）
```

命中第一条即终止匹配。UI 支持拖拽排序自定义规则。

## 10.8 DNS 分流

配套 DNS 路由规则：

| 流量类型 | DNS 处理 |
| --- | --- |
| 内网 DNS | 直连本地 DNS |
| 国内域名 DNS | 直连国内 DNS（223.5.5.5） |
| 代理域名 DNS | 通过代理远端 DNS（8.8.8.8） |
| TUN 53 端口 UDP | 劫持到内置 DNS 处理器 |

## 10.9 热重载

```
修改分流规则
    ↓
重新编译规则链
    ↓
调用 VPNManager.reloadConfig()
    ↓
sing-box 热重载路由配置
    ↓
已建立 TCP 连接沿用旧路由
    ↓
新连接使用新规则
    ↓
无需重启 TUN
```

## 10.10 核心 API

```swift
final class RouteRuleManager {
    static let shared = RouteRuleManager()

    func loadRules() throws
    func getAllRules() -> [RouteRule]
    func addRule(_ rule: RouteRule) throws
    func updateRule(_ rule: RouteRule) throws
    func deleteRule(id: String) throws
    func moveRule(id: String, to index: Int) throws
    func renderRules() throws -> [[String: Any]]
    func reloadRules() async throws

    // 规则集管理
    func updateRuleSet(tag: String) async throws
    func updateAllRuleSets() async
}
```

## 10.11 容错策略

| 异常 | 处理 |
| --- | --- |
| 规则语法错误 | 跳过该条，记录 WARN |
| 规则集下载失败 | 保留旧缓存，记录 WARN |
| 规则集 JSON 损坏 | 跳过该规则集，记录 ERROR |
| 热重载失败 | 回退到旧规则，记录 ERROR |
| 嗅探失败 | 降级为 IP 分流 |
