# 13 - 网络活动模块

## 13.1 职责

- 捕获四层 TCP/UDP 连接
- 五元组记录
- 嗅探域名
- 出站标签关联
- 流量统计
- IP 地理位置解析
- CSV 导出

> 不需要 MITM。与 HTTP 抓包互补：
> - 网络活动：四层连接，全部 TUN 流量
> - HTTP 抓包：应用层 HTTP 明文，仅 MITM 流量

## 13.2 数据模型

```swift
struct ConnectionSession: Identifiable {
    let id: String
    let startTime: Date
    var endTime: Date?
    let protocol: String           // tcp / udp
    let sourceIP: String
    let sourcePort: Int
    let destIP: String
    let destPort: Int
    var sniffedDomain: String?
    let outboundTag: String         // proxy / direct / block
    var matchedRuleName: String?
    var uploadBytes: Int
    var downloadBytes: Int
    var status: ConnStatus          // active / closed / blocked
    var ipGeo: IPGeo?
}

struct IPGeo: Codable {
    var country: String
    var asn: String
}

enum ConnStatus: String {
    case active
    case closed
    case blocked
}
```

## 13.3 IP 地理解析

- 使用离线 MMDB 文件（MaxMind / GeoLite2）
- 本地查询，不联网
- 首次启动自动下载 / 提示导入

## 13.4 内存策略

- 活跃连接池：保存当前活动连接
- 历史连接环形缓冲区：默认 300 条
- 可配置 100-2000
- 活跃连接不被清理
- 关闭连接自动移入历史

## 13.5 UI 面板

### 顶部控制栏

- 监控开关
- 暂停 / 继续
- 清空
- 导出 CSV
- 搜索

### 过滤条件

- 出站类型：proxy / direct / blocked
- 协议：TCP / UDP
- 状态：活跃 / 已关闭 / 拦截
- 忽略 DNS（UDP 53）

### 连接列表

字段：状态、协议、域名、目标 IP:端口、出站、规则、上行 / 下行、持续时间

### 详情弹窗

- 五元组
- 嗅探域名、匹配规则、出站
- IP 归属地、ASN
- 流量时序图

## 13.6 配置项

```json
"networkActivity": {
  "globalEnable": true,
  "maxHistoryConn": 300,
  "ignoreDnsConn": true,
  "mmdbPath": "app_data/geo/GeoLite2-Country.mmdb",
  "saveLogToFile": false
}
```

## 13.7 性能保护

- 连接生命周期回调，只读旁路
- UI 每 300ms 批量刷新
- 高频短连接（DNS）可过滤
- 测速隧道默认排除
- 关闭监控后零开销
