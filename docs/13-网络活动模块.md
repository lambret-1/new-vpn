# 13 - 网络活动模块

## 13.1 职责

- 捕获四层 TCP / UDP 连接
- 五元组记录
- 嗅探域名关联
- 出站标签关联
- 流量统计
- IP 地理位置解析
- CSV 导出

> 不需要 MITM。与 HTTP 抓包互补：
> - 网络活动：四层连接，全部 TUN 流量
> - HTTP 抓包：应用层 HTTP 明文，仅 MITM 流量

## 13.2 数据模型

```swift
struct ConnectionSession: Identifiable {
    let id: String
    let startTime: Date
    var endTime: Date?
    let `protocol`: ConnectionProtocol  // tcp / udp
    let sourceIP: String
    let sourcePort: Int
    let destIP: String
    let destPort: Int
    var sniffedDomain: String?         // 嗅探得到的域名
    let outboundTag: String             // proxy / direct / block
    var matchedRuleName: String?       // 命中的分流规则
    var uploadBytes: Int
    var downloadBytes: Int
    var status: ConnStatus
    var ipGeo: IPGeo?
}

enum ConnectionProtocol: String, Codable {
    case tcp
    case udp
}

enum ConnStatus: String, Codable {
    case active      // 活跃
    case closed      // 已关闭
    case blocked     // 被拦截
}

struct IPGeo: Codable {
    var country: String
    var countryCode: String
    var asn: String
    var org: String
}
```

## 13.3 IP 地理解析

- 使用离线 MMDB 文件（MaxMind GeoLite2）
- 本地查询，不联网
- 首次启动自动下载 / 提示导入
- 查询结果缓存到会话对象

## 13.4 内存策略

| 区域 | 容量 | 说明 |
| --- | --- | --- |
| 活跃连接池 | 无上限 | 当前活动连接，不被清理 |
| 历史连接缓冲区 | 默认 300 条 | FIFO 淘汰 |
| 可配置范围 | 100 - 2000 | UI 可调整 |

## 13.5 数据流转

```
sing-box 连接事件
    ↓
连接建立 → 创建 ConnectionSession
    ↓
五元组 + 协议 + 出站标签
    ↓
嗅探域名（TLS SNI / HTTP Host）
    ↓
匹配分流规则，记录规则名
    ↓
查询 IP 地理信息
    ↓
加入活跃连接池
    ↓
数据传输 → 更新流量统计
    ↓
连接关闭 → endTime 填入，移入历史缓冲区
```

## 13.6 配置项

```json
"networkActivity": {
  "globalEnable": true,
  "maxHistoryConn": 300,
  "ignoreDnsConn": true,
  "mmdbPath": "app_data/geo/GeoLite2-Country.mmdb",
  "saveLogToFile": false
}
```

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `globalEnable` | true | 总开关 |
| `maxHistoryConn` | 300 | 历史连接最大条数 |
| `ignoreDnsConn` | true | 忽略 DNS（UDP 53）连接 |
| `mmdbPath` | - | IP 地理库文件路径 |
| `saveLogToFile` | false | 是否持久化到文件 |

## 13.7 核心 API

```swift
final class NetworkActivityManager {
    static let shared = NetworkActivityManager()

    var isEnabled: Bool { get set }

    /// 暂停 / 继续采集
    func pause()
    func resume()

    /// 清空历史记录
    func clearHistory()

    /// 获取连接列表
    func getConnections(filter: ConnFilter?) -> [ConnectionSession]

    /// 导出 CSV
    func exportCSV(connections: [ConnectionSession]) throws -> URL
}

struct ConnFilter {
    var keyword: String?
    var outboundTags: [String]?
    var protocols: [ConnectionProtocol]?
    var status: ConnStatus?
    var ignoreDNS: Bool
}
```

## 13.8 性能保护

| 策略 | 说明 |
| --- | --- |
| 只读旁路 | 不阻塞主链路 |
| UI 节流 | 每 300ms 批量刷新 |
| DNS 过滤 | 可开关忽略 UDP 53 |
| 测速隔离 | 测速隧道默认排除 |
| 关闭后零开销 | 总开关关闭时不注册钩子 |

## 13.9 容错策略

| 异常 | 处理 |
| --- | --- |
| 嗅探失败 | 域名留空，仅显示 IP |
| MMDB 文件缺失 | 跳过 IP 地理查询，记录 WARN |
| MMDB 查询失败 | 跳过，不阻塞连接记录 |
| 缓冲区满 | FIFO 淘汰历史记录 |
| CSV 导出失败 | 提示错误 |
