# 14 - JS 脚本模块

## 14.1 职责

- 脚本 CRUD
- 启用 / 禁用
- 事件钩子调度
- 调用 JS 解释器执行
- 脚本编辑器
- 导入导出

## 14.2 触发类型

| 类型 | 说明 | 是否需要 MITM |
| --- | --- | --- |
| `httpRewrite` | HTTP 请求 / 响应事件 | 是 |
| `networkConnOpen` | 四层连接建立 | 否 |
| `networkConnClose` | 四层连接关闭 | 否 |
| `subscriptionUpdated` | 订阅更新完成 | 否 |
| `nodeSwitched` | 节点切换完成 | 否 |
| `tunnelStarted` | 隧道启动完成 | 否 |
| `tunnelStopped` | 隧道停止 | 否 |
| `timer` | 定时任务 | 否 |

## 14.3 数据模型

```swift
struct Script: Identifiable, Codable {
    let id: String
    var name: String
    var enable: Bool
    var description: String
    var trigger: TriggerType
    var match: ScriptMatch
    var scriptContent: String
    var timeoutMs: Int          // 默认 200ms
    var priority: Int           // 越小越先执行
    var logEnable: Bool
    var schedule: String?       // timer 类型的 cron 表达式
}

enum TriggerType: String, Codable {
    case httpRewrite
    case networkConnOpen
    case networkConnClose
    case subscriptionUpdated
    case nodeSwitched
    case tunnelStarted
    case tunnelStopped
    case timer
}

struct ScriptMatch: Codable {
    var domainSuffix: String?
    var pathRegex: String?
    var method: String?
}
```

## 14.4 内置 API

### $http（HTTP 事件上下文）

```javascript
// 获取请求信息
const url = event.url;
const method = event.method;
const headers = event.requestHeaders;
const body = event.requestBody;

// 修改请求
$http.setHeader("User-Agent", "Custom Agent");
$http.removeHeader("Cookie");
$http.setRequestBody("new body");

// 修改响应
$http.setResponseBody("modified");
$http.setResponseHeader("X-Custom", "value");

// 控制流程
$http.redirect("https://new.example.com");
$http.deny();           // 返回 403
$http.respond(200, "OK", {});  // 自定义响应

// 日志
$http.log("调试信息", "info");
```

### $network

```javascript
$network.log(`连接到 ${conn.sniffedDomain}`);
$network.getActiveConnections();
```

### $node

```javascript
$node.list();              // 获取全部节点
$node.getActive();         // 获取当前节点
$node.switch(nodeId);      // 切换节点
```

### $sub

```javascript
$sub.list();               // 获取订阅列表
$sub.refresh(subId);        // 刷新订阅
```

### $utils

```javascript
$utils.toBase64(str);
$utils.fromBase64(base64Str);
$utils.regexMatch(text, pattern);
$utils.md5(str);
$utils.notify("标题", "消息内容");
```

### $timer

```javascript
$timer.setTimeout(() => { ... }, 1000);
$timer.setInterval(() => { ... }, 5000);
```

## 14.5 事件调度流程

```
事件总线接收事件
    ↓
匹配触发类型
    ↓
遍历启用的脚本
    ↓
匹配规则条件（域名 / 路径 / 方法）
    ↓
命中 → 加入待执行列表
    ↓
按 priority 排序
    ↓
逐个调用解释器执行
    ↓
超时 / 异常捕获
    ↓
执行结果回写事件
    ↓
继续下一条脚本
```

## 14.6 安全限制

| 限制 | 说明 |
| --- | --- |
| 文件系统访问 | 禁止 |
| 网络请求 | 禁止（无 fetch / XHR） |
| 进程调用 | 禁止 |
| `eval` | 禁止 |
| 单脚本超时 | 默认 200ms |
| 单脚本内存 | 默认 1MB |
| 全局并发 | 默认 4 个 |

## 14.8 核心 API

```swift
final class ScriptManager {
    static let shared = ScriptManager()

    func loadScripts() throws
    func getAllScripts() -> [Script]
    func addScript(_ script: Script) throws
    func updateScript(_ script: Script) throws
    func deleteScript(id: String) throws

    /// 触发事件
    func triggerEvent(_ event: ScriptEvent) async

    /// 语法校验
    func validateSyntax(_ code: String) throws -> Bool

    /// 重置脚本上下文
    func resetContext(scriptId: String)
}
```

## 14.9 容错策略

| 异常 | 处理 |
| --- | --- |
| 语法错误 | 保存时拦截，脚本标记禁用 |
| 运行时异常 | 捕获，写日志，流量继续 |
| 超时 | 强制终止，记录 WARN |
| 内存超限 | 终止，记录 WARN |
| API 参数错误 | 返回 JS 异常，不崩溃原生 |
| 脚本导入 | 二次确认，提示安全风险 |
