# 14 - JS 脚本模块

## 14.1 职责

- 脚本 CRUD
- 启用 / 禁用
- 事件钩子调度
- 调用 JS 解释器执行
- 脚本编辑器
- 导入导出

## 14.2 触发类型

| 类型 | 说明 |
| --- | --- |
| httpRewrite | HTTP 请求 / 响应事件（MITM 解密后） |
| networkConnOpen | 四层连接建立 |
| networkConnClose | 四层连接关闭 |
| subscriptionUpdated | 订阅更新完成 |
| nodeSwitched | 节点切换完成 |
| timer | 定时任务 |

## 14.3 数据模型

```swift
struct Script: Identifiable, Codable {
    let id: String
    var name: String
    var enable: Bool
    var description: String
    var trigger: String
    var match: ScriptMatch
    var scriptContent: String
    var timeoutMs: Int          // 默认 200ms
    var priority: Int           // 越小越先执行
    var logEnable: Bool
}

struct ScriptMatch: Codable {
    var domainSuffix: String?
    var pathRegex: String?
}
```

## 14.5 执行流程

1. 事件总线接收事件
2. 匹配触发类型 + 匹配规则
3. 按 priority 排序
4. 逐个调用解释器执行
5. 超时 / 异常捕获，不中断主链路
6. 修改后的数据回写

## 14.6 安全限制

- 禁止访问文件系统
- 禁止网络请求
- 禁止进程调用
- 禁止 eval
- 单脚本超时限制
- 单脚本内存限制
- 全局并发限制（默认 4）

## 14.7 配置项

```json
"script": {
  "globalEnable": true,
  "defaultTimeoutMs": 200,
  "maxScriptMemoryBytes": 1048576,
  "maxConcurrentRun": 4
}
```

```swift
final class ScriptManager {
    static let shared = ScriptManager()

    func updateScript(_ script: Script) throws
    func deleteScript(id: String) throws

}
```
