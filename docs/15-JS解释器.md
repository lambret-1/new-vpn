# 15 - JS 解释器

## 15.1 职责

- 基于 JavaScriptCore 实现 JS 沙箱
- 脚本加载、编译、隔离执行
- API 桥接（JS ↔ Swift）
- 超时中断
- 语法校验
- 上下文管理

## 15.2 选型

| 方案 | 优势 | 劣势 | 选择 |
| --- | --- | --- | --- |
| JavaScriptCore（系统） | 原生框架，无依赖，JIT 性能好 | 需手动配置沙箱 | ✅ |
| 第三方 JS 引擎 | 功能丰富 | 增加体积，兼容性问题 | ❌ |
| WKWebView | 完整浏览器环境 | 重量级，沙箱难控制 | ❌ |

> macOS / iOS 均内置 `JavaScriptCore.framework`，无需引入第三方依赖。

## 15.3 沙箱初始化

```swift
import JavaScriptCore

final class SandboxContext {
    let context: JSContext

    init() {
        context = JSContext()!
        setupExceptionHandler()
        removeDangerousObjects()
        registerBridgingAPIs()
    }

    /// 异常处理
    private func setupExceptionHandler() {
        context.exceptionHandler = { ctx, exception in
            print("[JS错误] \(exception?.toString() ?? "未知错误")")
        }
    }

    /// 移除危险全局对象
    private func removeDangerousObjects() {
        context.globalObject.deleteProperty("fetch")
        context.globalObject.deleteProperty("XMLHttpRequest")
        context.globalObject.deleteProperty("WebSocket")
        context.globalObject.deleteProperty("require")
        context.globalObject.deleteProperty("process")
        context.globalObject.deleteProperty("window")
        context.globalObject.deleteProperty("document")
        context.globalObject.deleteProperty("eval")
        context.globalObject.deleteProperty("Function")
    }

    /// 注册桥接 API
    private func registerBridgingAPIs() {
        context.globalObject.setObject(NativeHttpBridge(), forKeyedSubscript: "$http" as NSString)
        context.globalObject.setObject(NativeNodeBridge(), forKeyedSubscript: "$node" as NSString)
        context.globalObject.setObject(NativeSubBridge(), forKeyedSubscript: "$sub" as NSString)
        context.globalObject.setObject(NativeUtilsBridge(), forKeyedSubscript: "$utils" as NSString)
        context.globalObject.setObject(NativeTimerBridge(), forKeyedSubscript: "$timer" as NSString)
    }
}
```

## 15.4 脚本入口规范

用户脚本固定实现 `main(event)` 函数：

```javascript
function main(event) {
    $http.log("脚本触发: " + event.url);

    // 修改请求头
    $http.setHeader("X-Custom", "value");

    // 条件判断
    if (event.host.includes("ads")) {
        $http.deny();
    }
}
```

### 执行流程

```
从上下文池取出独立 VM
    ↓
注入事件对象作为 main 入参
    ↓
启动超时计时器（默认 200ms）
    ↓
调用 evaluateScript 执行 main(event)
    ↓
正常完成 → 读取修改后的事件数据
    ↓
重置上下文变量，归还上下文池
```

## 15.5 资源限制

| 限制 | 默认值 | 说明 |
| --- | --- | --- |
| 单脚本超时 | 200ms | 超时强制终止 |
| 单上下文内存 | 1MB | 内存超限终止 |
| 全局并发 | 4 | 同时执行脚本数上限 |

### 超时实现

```swift
func runScript(code: String, event: [String: Any], timeout: TimeInterval) throws -> [String: Any] {
    // 启动超时计时器
    let watcher = TimeoutWatcher(timeout: timeout) {
        self.context.stopExecution()
    }
    watcher.start()

    // 注入事件
    context.globalObject.setObject(event, forKeyedSubscript: "event" as NSString)

    // 执行脚本
    let result = context.evaluateScript(code)

    watcher.cancel()

    // 读取结果
    return parseResult(result)
}
```

## 15.6 上下文池

- 每个脚本独立 JSContext
- 脚本加载时初始化
- 执行后重置变量，保留 VM 实例
- 支持手动重置（清空全局变量）
- 避免重复创建 VM 的开销

## 15.7 语法支持

### ✅ 允许

- `var / let / const`
- 普通函数、箭头函数
- 对象、数组、JSON
- 正则表达式（RegExp）
- Math、String、Array 内置方法
- 调用 `$` 桥接 API
- `console.log / warn / error`

### ❌ 禁止

- `async / await`、Promise
- `fetch`、XHR、WebSocket
- 文件读写（fs）
- 子进程、系统调用
- WebAssembly
- `eval`、`new Function()`
- `import / require`

## 15.8 日志输出

`console.log / warn / error` 桥接到原生日志：

```swift
private func setupConsole() {
    let consoleLog: @convention(block) (String) -> Void = { message in
        Logger.shared.info(module: "script", message: message)
    }
    let consoleObject = JSValue(object: consoleLog, in: context)
    context.globalObject.setValue(consoleObject, forProperty: "console")
}
```

## 15.9 异常处理

| 异常 | 处理 |
| --- | --- |
| 语法错误 | 预编译阶段拦截，脚本标记禁用 |
| 运行时异常 | 捕获，写日志，流量继续 |
| 超时 | 强制终止 JS 执行 |
| 内存超限 | 终止，记录 WARN |
| API 参数错误 | 返回 JS 异常，不崩溃原生 |
| 桥接异常 | 捕获，返回 JS undefined |

## 15.10 核心 API

```swift
final class InterpreterManager {
    static let shared = InterpreterManager()

    /// 语法校验（不执行）
    func validateSyntax(_ code: String) throws -> Bool

    /// 执行脚本
    func runScript(
        code: String,
        event: [String: Any],
        timeout: TimeInterval
    ) throws -> [String: Any]

    /// 重置脚本上下文
    func resetContext(scriptId: String)
}
```
