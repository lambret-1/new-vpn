# 15 - JS 解释器

## 15.1 职责

- 基于 JavaScriptCore 实现 JS 沙箱
- 脚本加载、编译、隔离执行
- API 桥接
- 超时中断
- 语法校验
- 上下文管理

## 15.2 选型

- macOS / iOS：系统自带 `JavaScriptCore.framework`
- 无需第三方依赖
- 自带 JIT，性能好
- 天然沙箱，无 IO / 网络 API

## 15.3 沙箱初始化

初始化时清除危险全局对象：

### 保留

- Object、Array、String、Number、Boolean
- RegExp、JSON、Math
- console

### 删除

- require
- fetch
- XMLHttpRequest
- WebAssembly
- File
- localStorage
- window
- process
- eval

### 注入

- `$http`、`$network`、`$node`、`$sub`、`$utils`、`$notify`

## 15.4 脚本入口规范

用户脚本固定实现 `main(event)`：

```javascript
function main(event) {
    $http.log("触发事件")
    // 业务逻辑
}
```

执行流程：

1. 从上下文池取出独立 VM
2. 注入事件对象
3. 启动超时计时器
4. 调用 `main(event)`
5. 读取修改后的数据
6. 重置上下文，归还池

## 15.5 资源限制

| 限制 | 默认值 |
| --- | --- |
| 单脚本超时 | 200ms |
| 单上下文内存 | 1MB |
| 全局并发 | 4 |

## 15.6 上下文池

- 每个脚本独立 JSContext
- 脚本加载时初始化
- 执行后重置变量，保留 VM 实例
- 支持手动重置上下文（清空全局变量）

## 15.7 支持语法

✅ 允许：

- `var / let / const`
- 普通函数
- 对象、数组、JSON
- 正则表达式
- 数学运算、字符串处理
- 调用内置 `$` API

❌ 禁止：

- `async / await`、Promise
- fetch、XHR、WebSocket
- 文件读写
- 子进程、系统调用
- WebAssembly
- `eval`、`new Function()`

## 15.8 日志输出

`console.log / warn / error` 桥接到原生日志缓冲区，归属 `script` 模块，携带脚本 UUID。

## 15.9 异常处理

| 异常 | 处理 |
| --- | --- |
| 语法错误 | 预编译阶段拦截，脚本标记禁用 |
| 运行时异常 | 捕获，写日志，流量继续 |
| 超时 | 强制终止，日志提示 |
| 内存超限 | 终止，日志提示 |
| API 参数错误 | 返回 JS 异常，不崩溃原生 |

## 15.10 核心代码结构

```swift
import JavaScriptCore

final class InterpreterManager {
    static let shared = InterpreterManager()

    /// 创建沙箱上下文
    private func createSandboxContext() -> JSContext {
        let ctx = JSContext()!
        // 删除危险对象
        ctx.globalObject.deleteProperty("fetch")
        ctx.globalObject.deleteProperty("XMLHttpRequest")
        // 注册桥接 API
        ctx.globalObject.setObject(NativeHttpBridge(), forKeyedSubscript: "$http" as NSString)
        return ctx
    }

    /// 执行脚本
    func runScript(code: String, event: [String: Any], timeout: TimeInterval) throws -> [String: Any]
}
```
