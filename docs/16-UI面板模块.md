# 16 - UI 面板模块

## 16.1 布局

采用 `NavigationSplitView` 三栏布局：

```
┌───────────┬────────────┬────────────────────────────┐
│ 侧边导航   │ 内容列表   │ 详情面板                    │
│ Sidebar   │ Content    │ Detail                      │
└───────────┴────────────┴────────────────────────────┘
```

| 栏位 | 宽度 | 说明 |
| --- | --- | --- |
| 第一栏（Sidebar） | ~200pt | 导航菜单，可折叠 |
| 第二栏（Content） | ~300pt | 条目列表 |
| 第三栏（Detail） | Flexible | 详情 / 表单 |

> 窄屏设备自动折叠侧边栏（系统原生能力）。

## 16.3 全局顶部状态栏

常驻任何页面：

```
┌──────────────────────────────────────────────────────────┐
│  [开关] ● 运行中  香港-01  ↑ 1.2MB/s  ↓ 8.5MB/s  [主题] │
└──────────────────────────────────────────────────────────┘
```

元素：

- 隧道开关按钮
- 状态指示灯（绿=运行 / 黄=连接中 / 红=断开）
- 当前节点名称
- 实时上下行速率
- 主题切换按钮

## 16.4 全局状态

```swift
final class AppState: ObservableObject {
    static let shared = AppState()

    @Published var tunnelState = TunnelState()
    @Published var selectedPage: PageType = .home
    @Published var theme: AppTheme = .system
    @Published var activeNodeName: String?
}

enum PageType: String, CaseIterable {
    case home
    case nodes
    case subscriptions
    case speedTest
    case route
    case mitm
    case capture
    case networkActivity
    case scripts
    case logs
    case settings
    case about
}

enum AppTheme: String, CaseIterable {
    case system
    case light
    case dark
}
```

## 16.5 弹窗规范

所有新增 / 编辑 / 高级详情弹窗：

1. 使用 `fullScreenCover`
2. 导航栏左上角返回按钮
3. 支持边缘左滑手势关闭
4. 独立导航栈，不污染主导航
5. 底部统一「取消｜保存」按钮
6. 危险操作二次确认

## 16.7 性能优化

| 策略 | 说明 |
| --- | --- |
| LazyVStack | 列表懒加载，海量数据不卡顿 |
| 节流刷新 | 流量、日志每 200-300ms 批量更新 |
| 状态隔离 | 高频数据用独立 `@Published`，避免全量重绘 |
| 编辑器防抖 | 语法校验停止输入后执行 |
