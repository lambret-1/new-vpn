# 16 - UI 面板模块

## 16.1 布局

采用 `NavigationSplitView` 三栏布局：

```
┌───────────┬────────────┬────────────────────────────┐
│ 侧边导航   │ 内容列表   │ 详情面板                    │
│ Sidebar   │ Content    │ Detail                      │
└───────────┴────────────┴────────────────────────────┘
```

- 第一栏：侧边导航菜单，可折叠
- 第二栏：当前功能的条目列表
- 第三栏：选中条目详情 / 表单

## 16.3 全局顶部状态栏

常驻任何页面：

- 隧道开关
- 当前节点名称
- 连接状态指示灯（绿 / 黄 / 红）
- 实时上下行流量
- 主题切换

## 16.5 弹窗规范

所有新增 / 编辑 / 高级详情弹窗：

1. 使用 `fullScreenCover`
2. 导航栏左上角返回按钮
3. 支持边缘左滑手势关闭
4. 独立导航栈，不污染主导航
5. 底部统一「取消｜保存」

- 卡片：代理状态 + 一键开关
