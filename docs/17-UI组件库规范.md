# 17 - UI 组件库规范

## 17.1 设计原则

1. **信息分层，减法优先**：次要功能收进折叠面板
2. **组件复用**：禁止业务页面手写独立控件
3. **交互统一**：相同操作行为一致
4. **文案统一**：术语、提示、警告标准化
5. **主题一致**：浅色 / 深色自动适配

## 17.2 语义化色彩

| 语义 | 浅色模式 | 深色模式 | 用途 |
| --- | --- | --- | --- |
| primary | 蓝色 | 浅蓝色 | 主按钮、高亮、激活 |
| secondary | 灰色 | 浅灰 | 次要文字、辅助说明 |
| success | 绿色 | 浅绿色 | 运行正常、成功 |
| warning | 橙色 | 浅橙色 | 警告、即将过期 |
| danger | 红色 | 浅红色 | 错误、断开、删除 |
| background | 白色 | 深灰黑 | 页面背景 |
| cardBackground | 浅灰 | 深灰 | 卡片背景 |
| separator | 浅灰线 | 深灰线 | 分割线 |

> 禁止页面内自定义颜色，全部引用语义色。

## 17.3 间距与圆角

```swift
enum UIConst {
    static let paddingSmall: CGFloat = 8
    static let paddingMid: CGFloat = 12
    static let paddingLarge: CGFloat = 16
    static let cornerRadius: CGFloat = 10
    static let cardPadding: CGFloat = 16
    static let formRowHeight: CGFloat = 44
}
```

| 常量 | 值 | 用途 |
| --- | --- | --- |
| `paddingSmall` | 8 | 紧凑间距 |
| `paddingMid` | 12 | 表单行间距 |
| `paddingLarge` | 16 | 卡片内边距 |
| `cornerRadius` | 10 | 卡片、输入框、按钮 |

## 17.4 字体层级

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| title | 28pt | bold | 页面大标题 |
| headline | 17pt | semibold | 卡片标题 |
| body | 14pt | regular | 主内容 |
| caption | 12pt | regular | 辅助说明 |
| metric | 20pt | bold | 数据指标 |

> 支持动态字体缩放，设置页可调字号。

## 17.5 基础组件

### AppCard

卡片容器，支持折叠：

```swift
AppCard(title: "代理状态", collapsible: false) {
    // 内容
}
```

### AppFormRow

表单行，左侧标签右侧控件：

```swift
AppFormRow(label: "MTU") {
    TextField("1500", text: $mtuText)
}
```

### AppButton

三种样式：

```swift
AppButton("保存", style: .primary) { save() }
AppButton("导出", style: .secondary) { export() }
AppButton("删除", style: .danger) { delete() }
```

| 样式 | 用途 |
| --- | --- |
| `.primary` | 主要操作（保存、启动） |
| `.secondary` | 次要操作（刷新、导出） |
| `.danger` | 危险操作（删除、重置） |

### StateBadge

状态标签：

```swift
StateBadge(text: "运行中", type: .success)
```

| 类型 | 颜色 |
| --- | --- |
| `.success` | 绿色 |
| `.warning` | 橙色 |
| `.danger` | 红色 |
| `.info` | 蓝色 |

### AppSearchBar

搜索栏，所有列表复用。

### AppConfirmDialog

危险操作二次确认弹窗。

### EmptyStateView

空白占位视图（图标 + 提示 + 操作按钮）。

## 17.6 列表规范

- 全部使用 `LazyVStack` 懒加载
- 行高统一，左侧标题 + 小字，右侧标签 / 按钮
- 顶部工具栏固定：搜索、新增、刷新、更多
- 点击进入详情，长按唤起上下文菜单

## 17.7 弹窗规范

- `fullScreenCover`
- 左上角返回按钮
- 边缘左滑关闭
- 底部「取消｜保存」
- 内容使用 `AppCard` + `AppFormRow`

## 17.8 术语统一

| 标准用词 | 禁止用词 |
| --- | --- |
| 隧道 | VPN、代理隧道 |
| 节点 | 服务器、节点服务器 |
| 订阅 | 订阅源、订阅链接 |
| 分流规则 | 路由规则 |
| 日志 | 调试日志 |
| 启用 / 禁用 | 打开 / 关闭（开关控件除外） |
| 保存 | 应用、确认 |
| 重置 | 恢复出厂 |
| 导出 / 导入 | 备份、加载 |

## 17.9 动画规范

- 仅保留基础过渡、卡片折叠
- 禁用弹跳、闪烁、旋转特效
- 状态更新使用淡入（0.2s）
- 开关、下拉使用原生动画

## 17.10 开发约束

1. 禁止业务页面写重复样式代码
2. 颜色、圆角、间距引用 `UIConst`
3. 新增页面必须复用已有组件
4. 公共组件修改自动全页面生效
5. 深浅主题全部验收
