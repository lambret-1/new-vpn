# 17 - UI 组件库规范

## 17.1 设计原则

1. **信息分层，减法优先**：次要功能收进折叠面板
2. **组件复用**：禁止业务页面手写独立控件
3. **交互统一**：相同操作行为一致
4. **文案统一**：术语、提示、警告标准化
5. **主题一致**：浅色 / 深色自动适配

## 17.2 语义化色彩

| 语义 | 用途 |
| --- | --- |
| primary | 主按钮、高亮、激活 |
| secondary | 次要文字、辅助说明 |
| success | 运行正常、成功 |
| warning | 警告、即将过期 |
| danger | 错误、断开、删除 |
| background | 页面背景 |
| cardBackground | 卡片背景 |
| separator | 分割线 |

> 禁止页面内自定义颜色，全部引用语义色。

## 17.3 间距常量

```swift
enum UIConst {
    static let paddingSmall: CGFloat = 8
    static let paddingMid: CGFloat = 12
    static let paddingLarge: CGFloat = 16
    static let cornerRadius: CGFloat = 10
}
```

## 17.4 字体层级

| 层级 | 用途 |
| --- | --- |
| Title | 页面大标题 |
| Headline | 卡片标题、分组标题 |
| Body | 主内容、列表文字 |
| Caption | 辅助备注、小字说明 |

> 动态类型兼容，设置页支持字号缩放。

## 17.5 基础组件

### AppCard

卡片容器，支持折叠：

```swift
AppCard(title: "代理状态") {
    // 内容
}
```

### AppFormRow

表单行，左侧标签右侧控件：

```swift
AppFormRow(label: "MTU") {
    TextField("", text: $mtuText)
}
```

### AppButton

三种样式：

```swift
AppButton("保存", style: .primary) { }
AppButton("导出", style: .secondary) { }
AppButton("删除", style: .danger) { }
```

### StateBadge

状态标签：

```swift
StateBadge(text: "运行中", type: .success)
```

### AppSearchBar

搜索栏，所有列表复用。

### AppConfirmDialog

危险操作二次确认弹窗。

### EmptyStateView

空白占位视图（图标 + 提示 + 操作按钮）。

## 17.6 列表规范

- 全部使用 `LazyVStack` 懒加载
- 行高统一
- 左侧标题 + 小字，右侧状态标签 / 按钮
- 顶部工具栏固定：搜索、新增、刷新、更多
- 点击进入详情，长按唤起上下文菜单

## 17.7 弹窗规范

- `fullScreenCover`
- 左上角返回按钮
- 边缘左滑关闭
- 底部「取消｜保存」
- 内容使用 `AppCard` + `AppFormRow`

## 17.8 术语统一

| 标准用词 | 禁止用词 |
| --- | --- |
| 隧道 | VPN、代理隧道 |
| 节点 | 服务器、节点服务器 |
| 订阅 | 订阅源、订阅链接 |
| 分流规则 | 路由规则 |
| 日志 | 调试日志 |
| 启用 / 禁用 | 打开 / 关闭（开关除外） |
| 保存 | 应用、确认 |
| 重置 | 恢复出厂 |
| 导出 / 导入 | 备份、加载 |

## 17.9 动画规范

- 仅保留基础过渡、卡片折叠
- 禁用弹跳、闪烁、旋转特效
- 状态更新使用淡入
- 开关、下拉使用原生动画

## 17.10 开发约束

1. 禁止业务页面写重复样式代码
2. 颜色、圆角、间距引用 `UIConst`
3. 新增页面必须复用已有组件
4. 公共组件修改自动全页面生效
5. 深浅主题全部验收
