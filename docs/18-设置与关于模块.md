# 18 - 设置与关于模块

## 18.1 设置页面结构

三栏布局：左侧分类菜单，右侧对应表单。

### 分类菜单

| 分类 | 说明 |
| --- | --- |
| 代理内核 | VPN/TUN 配置 |
| 日志配置 | 日志级别、文件 |
| 订阅配置 | 订阅全局参数 |
| UI 外观 | 主题、字号 |
| 备份与恢复 | 导入导出、重置 |
| 高级选项 | 自定义配置 |
| 关于本软件 | 版本信息 |

## 18.2 代理内核配置

对应 `config.json` 的 `vpn` 节点：

| 配置项 | 默认值 | 范围 | 生效方式 |
| --- | --- | --- | --- |
| MTU | 1500 | 1280-1500 | 重启隧道 |
| TUN 地址 | 10.0.0.2/30 | - | 重启隧道 |
| 自动路由 | true | 开关 | 重启隧道 |
| 自动 DNS | true | 开关 | 重启隧道 |
| 自动重连 | true | 开关 | 热生效 |
| 重试次数 | 3 | 1-10 | 热生效 |
| 重试间隔 | 2s | 1-10 | 热生效 |
| 统计间隔 | 500ms | 200-2000 | 热生效 |

## 18.6 备份与恢复

### 导出

- 打包全部配置为 ZIP
- 可选：密钥脱敏（默认开启）
- 可选：包含 CA 证书

### 导入

- 选择本地 ZIP 文件
- 二次确认弹窗
- 导入完成提示重启 App

### 重置

- 恢复出厂默认配置
- 弹窗强确认
- 重置前自动备份当前配置

## 18.7 高级选项

| 配置项 | 说明 |
| --- | --- |
| 自定义 sing-box 配置 | 文本框，追加到根配置 |
| 内核调试模式 | 开启 debug 级别内核日志 |
| IPC 超时设置 | 跨进程通信超时 |

> 保存前 JSON 语法预检。

## 18.8 配置变更生效策略

| 变更类型 | 生效方式 |
| --- | --- |
| UI 主题、字号 | 实时生效 |
| 日志级别 | 热生效 |
| 订阅全局参数 | 热生效 |
| TUN/MTU/路由/DNS | 重启隧道 |
| 高级内核配置 | 重启隧道 |
| 完整配置导入 | 重启 App |
| 恢复出厂 | 重启 App |

## 18.9 关于页面

### 展示信息

- 项目名称 + 版本号 `vX.Y.Z`
- 构建号（CI run number）
- 编译时间、Xcode 版本
- iOS 版本、设备型号
- sing-box 内核版本
- GitHub 仓库链接
- 开源协议
- 第三方库致谢

### 检查更新

- 检测远程最新版本
- 弹窗提示新版本
- 跳转 Release 下载页面

## 18.10 容错策略

| 异常 | 处理 |
| --- | --- |
| 表单输入越界 | 实时标红，禁止保存 |
| 导入文件损坏 | 弹窗提示，不覆盖 |
| 高级配置 JSON 错误 | 预检拦截 |
| 导出写入失败 | 提示错误 |
| 重置失败 | 自动恢复备份 |
