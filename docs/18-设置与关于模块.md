# 18 - 设置与关于模块

## 18.1 设置页面结构

三栏布局：左侧分类菜单，右侧对应表单。

### 分类菜单

1. 代理内核（VPN/TUN）
2. 日志配置
3. 订阅全局配置
4. UI 外观
5. 备份与恢复
6. 高级选项
7. 关于本软件

## 18.2 代理内核配置

对应 `config.json` 的 `vpn` 节点：

| 配置项 | 默认值 | 范围 |
| --- | --- | --- |
| MTU | 1500 | 1280-1500 |
| TUN 地址 | 10.0.0.2/30 | - |
| 自动路由 | true | 开关 |
| 自动 DNS | true | 开关 |
| 自动重连 | true | 开关 |
| 重试次数 | 3 | 1-10 |
| 重试间隔 | 2s | 1-10 |
| 统计间隔 | 500ms | 200-2000 |

> 修改内核参数需要重启隧道生效。

## 18.3 日志配置

对应调试日志模块：

| 配置项 | 默认值 |
| --- | --- |
| 日志级别 | info |
| 内存缓冲区条数 | 2000 |
| 文件日志 | 开启 |
| 单文件大小 | 5MB |
| 文件数量 | 10 |
| 敏感信息脱敏 | 开启 |

> 保存热生效。

## 18.4 订阅全局配置

| 配置项 | 默认值 |
| --- | --- |
| 拉取是否走代理 | 关闭 |
| HTTP 超时 | 30s |
| 内容大小上限 | 2MB |

> 保存热生效。

## 18.5 UI 外观

| 配置项 | 默认值 |
| --- | --- |
| 主题 | 跟随系统 |
| 表格字号 | 14 |
| 图表刷新间隔 | 500ms |

> 实时生效。

## 18.6 备份与恢复

### 导出

- 打包全部配置
- 可选：密钥脱敏
- 可选：包含 CA 证书

### 导入

- 选择本地文件
- 二次确认弹窗
- 导入完成提示重启 App

### 重置

- 恢复出厂默认
- 弹窗强确认
- 重置前自动备份

## 18.7 高级选项

- 自定义 sing-box 附加配置（文本框）
- 内核调试模式
- IPC 超时设置

> 保存前 JSON 语法校验。

## 18.8 配置变更生效策略

| 变更类型 | 生效方式 |
| --- | --- |
| UI 主题、字号 | 实时生效 |
| 日志级别 | 热生效 |
| 订阅全局参数 | 热生效 |
| TUN/MTU/路由/DNS | 重启隧道 |
| 高级内核配置 | 重启隧道 |
| 完整配置导入 | 重启 App |
| 恢复出厂 | 重启 App |

## 18.9 关于页面

### 展示信息

- 项目名称 + 版本号 `vX.Y.Z`
- 构建号
- 编译时间、Xcode 版本
- iOS 版本、设备型号
- sing-box 内核版本
- 版权声明、开源协议
- GitHub 仓库链接
- 功能清单
- 第三方库致谢

### 检查更新

- 检测远程版本
- 弹窗提示新版本
- 跳转下载页面

## 18.10 容错

- 表单输入校验：数值越界、非法 IP 实时标红
- 导入配置损坏：弹窗提示，不覆盖
- 高级配置 JSON 语法预检
- 导出写入失败：提示错误
- 重置前自动备份
