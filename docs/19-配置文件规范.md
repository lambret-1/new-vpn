# 19 - 配置文件规范

## 19.1 目录结构

```
app_data/
├── config.json                # 全局主配置
├── nodes.json                 # 节点库
├── subscriptions.json         # 订阅源
├── rules.json                 # 分流规则
├── rewrite.json               # MITM 重写规则
├── scripts.json               # JS 脚本
├── ca/
│   ├── ca.key.pem             # MITM 根私钥（加密存储）
│   └── ca.crt.pem             # MITM 根证书
├── rule_sets/                 # 远程规则集缓存
│   ├── geosite-cn.srs
│   ├── geoip-cn.srs
│   └── category-ads-all.srs
├── geo/
│   └── GeoLite2-Country.mmdb  # IP 地理库
├── cache/
│   └── speed_cache.json        # 测速缓存
└── logs/                       # 日志目录
```

## 19.8 版本迁移

每个配置文件头部 `version` 字段，启动时校验：

- 版本一致：直接加载
- 旧版本：执行迁移脚本，补齐缺失字段
- 无法识别：加载最近备份
