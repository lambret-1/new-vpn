# 21 - 风险清单

## 21.1 技术风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| NetworkExtension 权限限制 | 隧道无法启动 | 中 | 文档提示开启 VPN 权限；捕获权限错误，友好提示 |
| sing-box 内核崩溃 | 隧道中断 | 中 | Tunnel 捕获崩溃，上报主 App，触发自动重连 |
| 跨进程 IPC 不稳定 | 状态不同步 | 低 | 不中断隧道，日志告警，等待恢复 |
| JavaScriptCore 死循环 | 代理链路阻塞 | 中 | 超时强制终止，内存上限保护 |
| HSTS 站点 MITM 失败 | HTTPS 无法解密 | 高 | 日志提示，该域名走透传 |
| QUIC 流量无法 MITM | HTTP/3 无法解密 | 高 | 规则阻断 QUIC，降级 HTTP/1.1 |

## 21.2 性能风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| 大量日志内存占用 | 内存上涨 | 中 | 环形缓冲区限制条数，FIFO 淘汰 |
| 抓包大 Body 内存暴涨 | 内存溢出 | 中 | 文本截断 256KB，二进制默认不保存 |
| 高频短连接刷屏 | UI 卡顿 | 高 | 可开关忽略 DNS，列表懒加载 |
| 批量测速并发过高 | 网络拥堵 | 低 | 最多 3 个并发，自动限流 |
| 大量节点列表卡顿 | UI 不流畅 | 低 | LazyVStack 懒加载，虚拟滚动 |

## 21.3 数据风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| 配置文件损坏 | 设置丢失 | 低 | 原子写入，损坏自动加载备份 |
| 订阅格式不统一 | 解析失败 | 高 | 容错解码，单条失败不中断整体 |
| 订阅内容过大 | 内存耗尽 | 低 | 2MB 上限，超出直接终止 |
| 导出配置泄露密钥 | 隐私泄露 | 中 | 导出默认脱敏，可选保留 |

## 21.4 兼容性风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| 旧版本配置升级 | 字段缺失 | 中 | 版本迁移脚本，自动补齐默认值 |
| iOS 版本差异 | API 不可用 | 低 | 最低 iOS 16，按版本判断 API |
| 不同设备分辨率 | UI 错位 | 低 | Auto Layout + Safe Area 适配 |
| 深色模式适配不全 | 硬编码颜色 | 中 | 语义化颜色，全部主题验收 |

## 21.5 安全风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| CA 私钥泄露 | MITM 被伪造 | 低 | 加密存储，不明文导出 |
| 恶意 JS 脚本 | 系统被攻击 | 中 | 沙箱隔离，禁用文件 / 网络 / eval |
| 订阅内容含恶意脚本 | 代码执行 | 低 | 订阅只解析节点，不执行内容 |
| 日志记录敏感信息 | 隐私泄露 | 中 | 自动脱敏 UUID / 密钥 / Cookie |

## 21.6 工程风险

| 风险 | 影响 | 概率 | 应对方案 |
| --- | --- | --- | --- |
| CI 构建失败 | 无法出包 | 中 | 提交前本地编译自检，CI 日志排查 |
| 跨模块循环依赖 | 架构混乱 | 低 | 单向依赖原则，依赖检查 |
| 文档与代码不一致 | 维护困难 | 中 | 代码更新同步更新受影响目录 README |
| 版本号管理混乱 | 发布错误 | 低 | 三段式语义版本，CI 自动进位 |

## 21.7 风险等级矩阵

| 等级 | 风险数 | 说明 |
| --- | --- | --- |
| 高 | 3 | 内核崩溃、配置损坏、CA 私钥泄露 |
| 中 | 12 | 性能、兼容性、数据风险 |
| 低 | 5 | 工程流程风险 |

## 21.8 监控指标

| 指标 | 告警阈值 |
| --- | --- |
| 隧道崩溃率 | > 1% |
| 配置文件损坏次数 | > 0 |
| 内存峰值 | > 200MB |
| 日志队列溢出次数 | > 10 次/小时 |
| JS 脚本超时次数 | > 5 次/小时 |
| CI 构建成功率 | < 95% |
