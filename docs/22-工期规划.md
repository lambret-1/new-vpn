# 22 - 工期规划

> 项目名称：new VPN
> 项目类型：iOS SwiftUI 原生代理客户端，最低 iOS 16，sing-box 内核，PacketTunnel，GitHub Actions CI 打包，自用不上架 App Store
> 交付标准：可编译、CI 流水线产出未签名 IPA；全部模块代码、配套设计文档、README、工作流配置

## 一、前提约束

1. 人员：单人开发（iOS 架构师）
2. 开发环境：本地 Mac，Xcode 15.4，XcodeGen；远端 CI：macos-14 runner
3. 风险前置：GitHub macOS Runner 计费额度需提前配置，否则 CI 无法执行打包
4. 交付物：源码、所有模块设计文档、README、CI 工作流 yml；**不包含开发者证书、签名、TestFlight / App Store 上架工作**
5. 优先级原则：底层基础设施优先 → 核心隧道能力 → 业务管理模块 → UI 面板 → 扩展功能 → 测试 & 文档

## 二、整体总工期

**总预估工期：40 个工作日**

> 不含周末、节假日；不包含等待 GitHub CI 排队、系统网络异常、第三方内核适配排障的额外等待时间。
