## 22.10 风险与缓冲

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| GitHub Runner 额度不足 | 阻塞发布 | 本地手动打包，提前配置 Billing |
| sing-box 内核适配问题 | +1~3d | 预留排障缓冲 |
| 联调 BUG 较多 | +1~2d | 联调阶段弹性时间 |
| 订阅格式兼容问题 | +1d | 容错设计，收集错误日志 |

> 总缓冲：最多 3 个工作日，不计入 40 天基础工期。

## 22.11 验收标准

1. CI 成功产出 `newVPN-vX.Y.Z.ipa`
2. 全部代码注释、日志、UI 文案全中文
3. 所有 fullScreenCover 满足返回 + 左滑关闭
4. UI 统一使用封装组件，无硬编码样式
5. docs 目录全套文档齐全
6. 核心流程：隧道启停、节点切换、订阅更新、分流、抓包正常
7. 配置导入导出、日志脱敏、自动重连验收通过
