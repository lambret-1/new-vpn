# 23 - 版本更新模块设计

> 手动检查更新 + 后台自动检测更新方案。
> iOS 沙盒限制：无法静默安装 IPA，仅检测 + 提示 + 跳转下载。

## 23.1 功能清单

### 手动检查更新

- 入口：关于页面 → 「检查更新」
- 流程：请求 GitHub Release API → 对比版本 → 提示 → 跳转下载

### 自动后台检测

- 设置页开关：App 启动时自动检测（默认开启）
- 触发：App 启动后异步后台请求，不阻塞 UI
- 冷却：24 小时内不重复检测
- 仅检测到新版本才弹窗提示

## 23.2 版本对比规则

- 格式：`vX.Y.Z`，去除 `v` 前缀
- 依次比较：主版本 > 次版本 > 补丁版本
- 仅识别正式 Release，忽略 draft / prerelease
- 示例：本地 `v0.1.5`，远程 `v0.2.0` → 判定有新版本

## 23.3 数据模型

```swift
struct RemoteReleaseInfo: Codable {
    let tagName: String           // "v1.2.3"
    let releaseNote: String      // 更新日志 markdown
    let publishedAt: Date
    let downloadUrl: String      // IPA 下载地址
    let isDraft: Bool
    let isPrerelease: Bool
}

struct AppUpdateConfig: Codable {
    var autoCheckOnLaunch: Bool   // 启动自动检测
    var lastCheckTimestamp: Double // 上次检测时间戳
    var checkCooldownHour: Int     // 冷却小时数，默认 24
}
```

## 23.4 API

```swift
final class AppUpdateManager: ObservableObject {
    static let shared = AppUpdateManager()

    /// 手动检查更新（带 Loading 弹窗）
    func checkUpdateManually() async throws -> RemoteReleaseInfo?

    /// 后台自动检测（无 UI 阻塞，有新版本才返回）
    func checkUpdateBackground() async

    /// 版本比较：远程 > 本地返回 true
    func isNewVersionAvailable(local: String, remote: String) -> Bool
}
```

## 23.5 GitHub API

```
GET https://api.github.com/repos/lambret-1/new-vpn/releases/latest
```

- 公开仓库，无需 Token
- 解析 `tag_name`、`body`、`published_at`、`assets`
- 在 assets 中匹配 `newVPN-v*.ipa`，提取 `browser_download_url`
- 403 限流：静默跳过（后台）或提示（手动）

## 23.6 UI 交互

| 位置 | 元素 | 说明 |
| --- | --- | --- |
| 设置页 | 开关：启动时自动检测 | Toggle，持久化 |
| 关于页 | 按钮：检查更新 | Secondary 样式 |
| 新版本弹窗 | 标题 + 更新日志 + 前往下载 / 稍后 | AppConfirmDialog |
| 已是最新 | Toast 提示 | 2.5s 自动消失 |

## 23.7 配置项

```json
"appUpdate": {
  "autoCheckOnLaunch": true,
  "lastCheckTimestamp": 0,
  "checkCooldownHour": 24
}
```

## 23.8 容错策略

| 异常 | 处理 |
| --- | --- |
| 无网络 | 静默失败，写日志；手动模式弹窗提示 |
| API 限流（403） | 后台静默跳过；手动提示受限 |
| Release 无 IPA 产物 | 日志警告，提示未找到安装包 |
| tag 格式不匹配 | 跳过，日志记录解析失败 |
| 后台任务超时 | 10s 超时取消 |
