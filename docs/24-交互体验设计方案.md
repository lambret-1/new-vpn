# 24 - 交互体验设计方案

> 统一整套 App 的交互逻辑、反馈、状态流转、手势、加载、空态、错误提示。
> 降低认知成本，操作直觉一致，遵循全局 UI 组件规范。

## 24.1 核心交互原则

1. **操作可逆，高危二次确认**：删除、重置、批量清除必须确认弹窗
2. **即时反馈**：点击、加载、成功、失败都有反馈，禁止无响应点击
3. **非阻塞后台任务**：订阅更新、测速、版本检测全部异步执行
4. **状态可见**：隧道、节点、订阅状态始终可视化
5. **最小打扰**：后台任务仅在有新内容时弹窗；普通失败静默写日志
6. **手势统一**：fullScreenCover 左上角返回 + 左滑关闭
7. **容错优先**：单条失败不中断整体流程
8. **简化决策**：表单默认合理值，复杂功能折叠进高级选项

## 24.2 通用交互规范

### 按钮交互

- 三种样式：primary / secondary / danger
- 点击缩放淡入反馈（SwiftUI 原生）
- 禁用态置灰，不可点击
- 1 秒防抖，防止重复触发
- 任务执行期间按钮置灰 + Loading

### 弹窗规范（fullScreenCover 强制）

- 导航栏左上角返回按钮
- 边缘左滑关闭
- 底部操作栏：`取消｜保存`，顺序固定
- 脏数据检测：有未保存修改时关闭，二次询问「是否放弃修改？」

### 加载态

| 任务时长 | 展示方式 |
| --- | --- |
| < 1s | 不展示 Loading，避免闪烁 |
| 1-5s | 页面内嵌入 Loading 占位 |
| 后台任务 | 状态栏小字提示，不弹窗 |

### 空状态（EmptyStateView）

全部列表空页面统一：图标 + 提示文字 + 操作按钮

| 场景 | 提示 |
| --- | --- |
| 无节点 | 暂无节点，点击新增 |
| 无订阅 | 暂无订阅源，添加订阅链接 |
| 无抓包记录 | 启动隧道后即可捕获 HTTP 流量 |

### 提示分级

| 级别 | 形式 | 适用场景 |
| --- | --- | --- |
| 轻量 | Toast（2.5s 自动消失） | 保存成功、导出完成 |
| 弹窗 | AppConfirmDialog | 错误、警告、新版本、高危确认 |
| 静默 | 仅写日志 | 后台任务失败、网络错误 |

### 列表交互

- LazyVStack 懒加载
- 点击条目 → 右侧详情面板
- 长按条目 → 上下文菜单（复制、编辑、删除）
- 顶部工具栏：搜索、新增、刷新、更多
- 搜索实时过滤

### 表单交互

- 输入框实时校验，非法输入标红
- Toggle 即时生效
- 需要重启隧道的选项，保存后提示
- 高级选项默认折叠
- 数值输入范围限制（如 MTU 1280-1500）

## 24.3 各页面专项交互

### 主控首页

- 大状态按钮：启动 / 停止，根据状态切换文字与颜色
- 实时流量：500ms 节流刷新
- 状态流转：点击启动 → 准备中 → 连接中 → 运行
- 断连重连：显示「重连中」，可手动停止

### 节点管理

- 列表展示名称、协议、延迟
- 切换节点：隧道运行中弹窗确认「隧道将重启」
- 长按上下文菜单：复制链接、编辑、删除
- 批量多选删除

### 订阅管理

- 展示名称、上次更新时间、流量 / 过期信息
- 立即更新：后台执行，成功 Toast 提示
- 部分失败：弹窗显示成功 / 失败数量
- 自动刷新：后台静默，完成 Toast 提示

### 测速中心

- 批量测速：实时状态（等待 / 测速中 / 完成 / 失败）
- 可随时停止
- 完成自动刷新延迟数据
- 分片执行，防止并发过载

### 分流路由

- 规则列表拖拽排序
- 修改规则热重载，提示无需重启隧道

### MITM 重写

- 证书生成后提供导出
- 规则启用 / 禁用即时生效
- 联动跳转抓包页面

### HTTP 抓包

- 实时追加会话列表
- 用户上滑查看历史时暂停自动滚动
- 点击展开详情（请求 / 响应 / Body）
- JSON 自动格式化
- 清空、导出 HAR

### 网络活动

- 实时连接列表
- 连接关闭自动标记
- 过滤协议、出站策略
- 导出 CSV

### JS 脚本

- 启用 / 禁用开关
- 优先级拖拽排序
- 编辑器实时语法校验
- 执行超时自动终止

### 调试日志

- 实时追加，级别过滤
- 搜索过滤
- 一键清空、导出
- 环形截断防内存暴涨

### 设置

- 表单分组：隧道、日志、订阅、UI、备份、高级
- 每个选项标注生效方式：热生效 / 重启隧道 / 重启 App
- 导出支持密钥脱敏
- 导入二次确认
- 重置高危二次确认

### 关于 & 版本更新

- 展示版本号、内核版本、仓库链接
- 检查更新：手动触发，加载状态
- 新版本弹窗：版本号 + 更新日志 + 前往下载
- 自动检测：启动后台异步，24h 冷却，仅新版本弹窗

## 24.4 手势清单

| 手势 | 场景 |
| --- | --- |
| 左滑边缘 | fullScreenCover 弹窗返回 |
| 长按 | 列表条目上下文菜单 |
| 拖拽 | 规则 / 脚本优先级排序 |
| 长按复制 | 文本区域 |
| 自动折叠 | 大屏三栏，iPhone 折叠侧边栏 |

## 24.5 防误操作

1. 删除当前使用节点：弹窗确认「该节点正在使用，删除会停止隧道」
2. 任务执行中禁止强制中断，捕获中断记录日志
3. 编辑弹窗未保存退出：提示放弃修改
4. 并发互斥：同一时间只允许一次订阅更新、一次批量测速

## 24.6 动效规范

- 页面切换：SwiftUI 默认淡入
- 卡片折叠：简单高度动画
- Toast：淡入淡出 2.5s
- 禁止：弹跳、旋转、闪烁、粒子特效
- 状态颜色：平滑过渡

## 24.7 无障碍

- 按钮 / 开关 / 标签增加 accessibilityLabel
- 支持动态字体缩放
- 颜色不只依靠色相，搭配文字标签

## 24.8 性能交互优化

| 策略 | 说明 |
| --- | --- |
| 节流刷新 | 流量、日志 200-500ms 批量更新 |
| Lazy 懒加载 | 列表虚拟滚动 |
| Task 自动取消 | 页面销毁自动 cancel |
| 网络超时 | 防止请求挂起 |
